# 可学习的补偿表示与有限粒子目标的选择

这是本轮精简核心陈述，不是新的完整稿。封存的v3.1正文与PDF保持原样；以下实验结果已经封存并通过独立审计。

低风险表示的存在与粒子目标是否选择它，是两个不同问题。对弱正公共因子Gaussian-logistic教师，即使所有潜在边际尺度都降到固定正下限，也可通过调整载荷，把完整观察KL控制到O(d^-2)，同时保持严格正谱上下界。但解析匹配的载荷使用了教师参数。当前问题是：是否能仅从观察中学到补偿，以及连续似然目标实际会选择什么表示？

**已知组下，补偿可以由非oracle观察学习。** 教师具有两个已知等大组、零均值和正公共因子，ρ_d=c/(d−1)；真实c和两个尺度未知，但处在固定范围内，c有正下界。候选固定潜在尺度为a，仅学习两个有效幅度w_g，载荷为w_g/√(d−1)。

一个简单矩估计器使用各组自旋和平方的样本均值，以已知floor响应α(a)=E[Z tanh(aZ/2)]归一化，再按预先指定的区间clip并开平方。它不输入teacher PMF、真实尺度、真实c或oracle载荷。对N条独立完整观察，
\[
\sup_{\text{允许教师}}
E\,D(P_d^\star\Vert Q_{\widehat w,d})
\le C(d^{-2}+N^{-1}).
\]
证明用组和的维数统一四阶矩处理向量内依赖，保留有限d的Hermite余项，再将载荷误差直接传到完整观察forward KL，没有使用KL三角不等式。N的单位是d位向量，观察bit成本仍为Nd。估计对象是有效幅度w，不是分别恢复原尺度和c。

在明确的尺度分离及维度条件下，另一个经独立审读的[split扩展](UNKNOWN_GROUP_THEORY.md)可先用 \(n_1=O(d\log d)\) 条向量恢复组身份，再用独立的 \(n_2=d^2\) 条达到O(d^-2)期望joint KL；它是理论扩展，当前实验仍使用已知组，没有未知组新实验。

**边际化保证可以容许表示近似误差。** 本轮不假定有限d教师观察分布精确包含在固定下限类中，也不证明所有w都不可能观察等价。对一个可行比较表示 \(Q_0\)，记 \(r_d=D(P_d^\star\Vert Q_0)\)。私噪声边际化目标的逐标签bias上界为 \(\mathcal B_d=O(d)\)，自身模型下的平均bias至多 \(C\omega_K\)。加权Hellinger不等式把它转移到实际教师，得到
\[
D(P_d^\star\Vert Q_{\widehat w})
\le\varepsilon+r_d+
\left(\sqrt{C\omega_K}+\sqrt{\mathcal B_dr_d}\right)^2,
\]
其中ε控制总体目标相对比较模型的差。存在r_d=O(d^-2)的补偿、K=d及总优化误差趋零时，完整joint KL仍趋零。

连续经验目标也有明确桥接：对共享B个bank、N个标签，用确定性参数网格和Gaussian最大值控制得到全连续域的目标误差界。在K=d、N=B=d²、网格逐渐加密及数值误差受控的路径上，全局经验近优点或完整网格ERM可在概率与期望中一致。该定理不为固定多起点优化器提供全局证书。

**实际粒子评分未必偏好已经可学到的好表示。** 实验采用d16/64、每维8条独立流、N256/4096、B64、K=d及相同候选盒[.5,2.5]²。raw与col共用标签和公共因子bank，MOM与数值准MLE使用同一标签；同K不是同计算成本。128个输出全部先封存再评价。96个连续选点在9个固定起点后通过投影梯度、差分和网格诊断，但这些检查不认证连续全局最优。

N4096时，8流平均的完整观察KL为：

|d|raw|MOM|col|数值准MLE|
|---:|---:|---:|---:|---:|
|16|0.030105|0.000291|0.001237|0.000178|
|64|0.033366|0.000267|0.000257|0.000161|

d64的raw−MOM与raw−col原风险门均通过。独立bank却估计raw所选模型的**原始评分更低**：raw所选减MOM为−.04647总nats，原同时近似区间为[−.05740,−.03555]。因此低风险补偿已能从观察中学到；这次raw程序选出的模型尽管独立估计的raw目标更低，观察风险却更高。

边界同样清楚。原风险主门5/8通过，独立raw−MOM评分门2/2通过。d16的raw−MOM、raw−col虽区间下端为正，但SE超过预定.002，主门不通过；d16 col−准MLE也未过.001非劣门。风险精度18/24、评分精度12/16，所有失败保留。两套t近似家族分开，数值资格也不是严格积分余项证书。

所有候选的单比特边际都为1/2。作为原定中央事件的描述性读数，d64/N4096下 \(|\sum_iY_i|\le\sqrt d\) 的真实概率为.6527；raw与MOM的平均绝对概率误差分别为.0917和.00572。这里不新增置信区间或成功门，也不以平均预测接近代替逐流误差。

当前预算下，连续目标误差粗界本身约为d16的7.65、d64的17.15 nats，尚未加数值和全局优化误差。它提供充分渐近路径，不认证当前小的实测KL。

MOM是经典有限信息思想下的基线。低阶二元矩用于因子或关联估计已有[Wu–Bentler](https://doi.org/10.1016/j.csda.2012.06.022)与[Shi等](https://arxiv.org/abs/2404.08457v1)的直接先例。拟主张的增量应落在本受限模型中“完整观察风险保证—有限粒子目标偏好—实际是否学到补偿”的连接，而不是提出新的通用矩算法。当前实验给定组身份；split理论中组身份未知，已知的是组大小、floor响应和参数范围（含尺度分离），并使用独立两批样本。正载荷、零自旋边际（二值边际1/2）等模型条件仍保留，数值/优化资格按各合同陈述。
