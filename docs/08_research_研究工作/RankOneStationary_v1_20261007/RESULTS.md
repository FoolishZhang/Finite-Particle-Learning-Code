# 联合驻定后，共线F8局部稳定仍然保留

本轮完成五个固定期望F8求解：四个原经验目标E0–E3，以及同一教师的总体目标P。**五点均达到预定的完整驻定/局部极小数值签名：16个偏置/行长方向与7个非旋转横向方向全部正。总体P仍存在明确风险下降方向，而F8排斥该方向的有限小步。** 这补上前轮只固定偏置/行长的条件几何缺口。

## 实际执行与核验

- 五次确定性优化共接受13步，调用内核30次（17次完整二阶、13次FG）；两阶段各自按预定梯度门停止。E0/E1各2步，E2/E3/P各3步。未追加起点、预算或回溯。所有实际Newton移位为0、限幅比例为1，13个trial均在首个alpha被接受；制造测试另覆盖阻尼、回溯失败和预算停止。
- 终点评价27个目标/K块，C/D共54块；五探针各3块，C/D共30块。评价共20次内核调用。50次科学内核调用共计算1,336,606,720个高层Laplace指数因子；这是确定性节点因子计数，不是独立随机样本数或CPU指令计数。
- 新观察、随机prior和统计alpha均为0。求解约27.15秒，最终评价约150.67秒，不含开发、制造核验与记录开销；不把这与旧随机Adam成本等同。
- 27/27终点块、5/5探针点通过预定数值门。终点C/D最大loss差1.505e−11，梯度差9.283e−13，H_ba差1.112e−11，横向矩阵差1.049e−11，角度矩阵差3.304e−14。
- [独立执行核验](../../../artifacts/rankone_stationary_v1_20261007/AUDIT.json)通过11094项检查：读取全部50次保存调用、55个NPZ；重建label聚合、求解步长与接受规则、预算、锁与探针。另以独立节点构造和自适应外积分重算五终点各四个固定标签，共20项K8标签核验，loss最大差6.484e−13、H_ba最大差4.008e−14。
- 这不是整轮独立重新优化，也不是严格Gaussian/辅助积分余项证书。18项内核/求解器制造测试和审计制造测试532项断言均已通过。全部失败分支在制造夹具核验；真实本轮没有未过门、越预算或非有限失败。旧研究失败和别名勘误不改写。

55个NPZ共98,050,684字节继续本地保留且被Git忽略。公开Git含可读参数、矩阵、谱、逐步记录与绑定哈希；原始数组备份是另一项操作，本轮没有制作压缩包。
