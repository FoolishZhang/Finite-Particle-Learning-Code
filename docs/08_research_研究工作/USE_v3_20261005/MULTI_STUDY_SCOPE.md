# 两项研究的联合报告范围

本文件在USE-v3仍执行、尚未读取其总体测试结果时写入。USE-v2合成研究的15项原家族保持；USE-v3自然数据研究的5项原家族保持，不改任何候选、样本、阈值或冻结推断。

因为自然数据研究是在看到合成研究未确认实质RAW100危害后开展的，必须将这一探索历史与全部阴性/未决结果一起报告。不能把第二项结果冒称从未经历场景探索的外部确认。

在两项结果完成后，另对全部20个主要比较给出Bonferroni alpha.05、各自df31的更严格敏感性区间。它只是扩大原区间的联合呈现，不替换旧主区间，也不增加科学采样。两个研究分别是合成新数据流推断和固定benchmark条件随机化推断，不混合其效应单位或求一个总平均。

对自然数据的实质阳性判断应说明是否在该更严格检查下仍成立，并单独列出原SE精度目标；即使有某个阳性，也不能隐藏原工作流不支持普遍危害的事实。该校正仍使用开发t近似，不解决自然数据代表性、模型选择外部效度或未来工作流探索的所有多重性问题。
