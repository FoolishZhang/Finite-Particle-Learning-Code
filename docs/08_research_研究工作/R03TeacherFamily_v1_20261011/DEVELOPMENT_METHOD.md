# R03 有界数值开发方法

本页对应 `script/r03_development_compute.py`。驱动实现完成不等于科学执行授权或冻结；调用者先冻结输入、源码、门限和预算，再调用 `compute`。本阶段提供数值开发证据，不认证真实根、严格 Hessian、连续参数区间或一般优化器行为；v1.9.1 和旧研究证据不改写。

## 输入和固定教师

`initial_exact` 是 `artifacts/certified_teacher_v1_20261008/CANDIDATE_RISK_INTEGRALS.json` 的八项 `a_exact` 有理数字典。`direction` 是 `artifacts/angular_witness_v1_20261010/DIRECTION.json`，固定 `d=u/sqrt(S)`；驱动检查八项整数、`sum(u)=0`、`S=sum(u²)>0`，不重新挑选方向。浮点数是这些指定精确数的计算表示，不是新的精确证书。

教师 bias 全零，八行行长均为精确 `4/5`，角度为

`(-7/10,-5/10,-3/10,-1/10,1/10,3/10,5/10,7/10)+lambda*e1`。

七个固定开发点按 `0,+1/100,-1/100,+1/20,-1/20,+1/10,-1/10` 处理；不接受更换或追加点的 `lambdas` 参数。基点从旧精确中心启动，正负支分别使用上一合格同侧点，种子索引依次为 `null,0,0,1,2,3,4`。上一点根求解、教师资格或 C/D 资格失败，则该支的后续点保留为阻塞；基点失败阻塞两支。未自动调整步距、回退到较早种子或新增搜索。

教师通过原纯核 `joint_dependence_kernel.model_pmf` 计算完整 256 标签，GH60 为主目标；GH80 和旋转 `.271` 弧度的 GH80 是独立网格数值检查。每个原始概率向量逐项保存，不归一化，不进行对称平均。记录三个两两 L1 差、原始质量误差、补标签对称残差，以及精确理论应为 `1/2` 的观察边际误差。默认门为三个 L1 差均不超过 `1e-10`；调用者可在执行前冻结完整 `gates` 字典覆盖该默认值。GH 对照只提供数值资格，不给严格求积误差界。

## 秩一径向求根

仅求八个径向坐标 `a`，固定 `b=0`，每个调用都用原纯核 `rankone_stationary_kernel.rankone_stationary` 的完整 256 标签表达。教师零偏置的精确补标签对称使 bias 梯度理论为零；实际完整 16 维梯度仍保留检查，不用零向量覆盖计算值，不使用原 41 类压缩。

|规则|Gaussian 积分|log-u 梯形网格|用途|
|---|---|---|---|
|O|GL128，区间 `[-10,10]`|`[-24,48]`，步长 `.25`，289 节点|最多 10 次 Newton 迭代，径向梯度无穷范数 `<=1e-8`|
|C|GL256，区间 `[-10,10]`|`[-28,56]`，步长 `.25`，337 节点|最多 6 次修正，径向梯度无穷范数 `<=1e-11`；最终完整评估|
|D|GL384，区间 `[-11,11]`|`[-32,64]`，步长 `.125`，769 节点|最终独立网格完整评估|

每次 Newton 迭代用 `Haa*step=-g_a` 的直接线性求解，不加 ridge、裁剪或 Hessian 谱修正。试探依次为 `alpha=2^-h`，`h=0,...,8`，候选必须位于闭盒 `[.1,1]^8`。接受条件固定为

`||g_a(a+alpha*step)||inf <= (1-1e-4*alpha)||g_a(a)||inf`。

试探调用只计算梯度；接受后的下一次 Newton 迭代再计算 Hessian。试探已达到停止门时立即结束该阶段。每次试探、盒约束拒绝、梯度拒绝、奇异矩阵、迭代耗尽都保留，预算耗尽不自动重试。O 阶段失败则不继续 C 阶段；已完成的参数、梯度、Newton 步、阻尼和接受原因保留在 `root_phases`，每个实际核调用另在 `call_log` 记录精确参数、完整梯度、规则和工作量。

## 最终读数和数值门

在最终同一 `a` 上分别用 C/D 计算 `K=(8,"inf")`，`compute_hessian=True`。保存原核完整返回，包括完整 16 维梯度、16×16 `H_ba`、8×8 `Hperp/Hangle`、所有 `label_*` 项、正常/外层节点和权重。`return_coefficients=False`：不保存 `[label,node]` 的可选 c/d 系数，也不保存巨大的 `[label,outer,node]` 临时因子；每标签 c/d 总质量仍完整保留。中间 Newton 调用保留紧凑轨迹和实际工作量，不保留全部临时数组。

每个 K 计算完整 Hba 的最小特征值、`a` 正交补上的七个横向特征值、固定 `d` 的角曲率和 Ward 残差。正交补用确定性 Householder：`u=a/||a||`，`v=u+sign(u0)e0`，`sign(0)=1`，`V=(I-2vvT/(vTv))[:,1:]`；不导入会读写文件的旧运行模块。特征值使用矩阵的显式对称部分，原矩阵及非对称残差同时保留，不裁剪特征值。

默认 C/D 门为：完整梯度（两个 K 全坐标）最大绝对差 `<=1e-7`；两个 K 的 Hba/Hperp/Hangle operator 差均 `<=1e-5`；固定风险角曲率差 `<=1e-7`。门失败原样保留，不加阶、改步长或放宽门。门通过仅表示该规定比较通过；正曲率、负风险曲率以及大小界由后续读数和科学判断处理。

同时保存 `a-a0`、反序配对 `a_j-a_(7-j)`、教师相对基点 L1、全 8×8 spin 二阶矩及其相对变化、标签反序对称破坏、候选模型完整 PMF 与原始质量，以及未归一化求积读数

`risk_KL = loss_inf + sum_y q_y log(q_y)`。

该式使用当点教师原始 GH60 概率和候选原始 GL 概率，不把数值质量误差静默消去。

## 时间、停止和账目

默认总计算预算 600 秒，允许调用者减少，不允许增加。每次教师/目标核调用前检查预算和 `stop_requested()`；每个已完成调用和点可通过 `checkpoint(state)` 保存公开 JSON 状态。调用者写出 checkpoint 的耗时从计算预算中扣除，驱动没有自身文件 I/O、RNG 或 NPZ。

这是调用边界合作停止：已经进入的 NumPy/SciPy 调用不能由纯驱动抢占。返回保留已完成部分，并明确记录超过 600 秒的尾差；若调用者要求严格硬截止，需要在外层使用进程级截止并保留先前 checkpoint。已开始/完成/失败的调用分别计数；异常调用的内部执行量未知，明确记录而不虚构精确计数。成功目标调用的标量因子计数逐项采用原核 `work_counts`；教师计数是每网格 `order²` Gaussian 节点、`256*order²` 条件似然值、`8*order²` logit 值和 256 标签积分。这些是高级标量量计数，不是 CPU 指令数，也不是独立随机样本。

API：

```python
result = compute(
    initial_exact=old_risk["a_exact"],
    direction=old_direction,
    wall_seconds=600,
    checkpoint=save_state,       # 可选；仅调用者负责持久化
    stop_requested=should_stop, # 可选
)
```

模块直接运行仅执行 `manufactured_checks()`，不提供命令行科学执行入口。制造夹具检查 Newton 单步收敛、梯度试探、九次试探耗尽、Householder 基、立即停止、七点占位保留、严格 JSON、正负支分开种子、原始概率保留、目标调用账目、三教师网格节点账目和基点 C/D 失败阻塞规则。所有这些检查注入制造核，真实教师与目标调用均为零；收据见 `artifacts/r03_teacher_family_v1_20261011/DEV_IMPLEMENTATION_CHECK.json`。
