# USE-v2结果：可用联合模型已学得，但K100的实质选模危害未确认

本轮首次执行了独立训练/验证/测试的新数据流程：3个生成条件×32重复，288个joint终态与96个独立拟合。必须保留的结论是：**本候选池没有确认RAW100相对高精度参照的实质额外风险，不能把它包装成实践危害成功。** 更高预算INNER1600相对GH的风险上界在三个条件均低于预定0.0002；OUT16与INNER1600的差额上界也都低于该尺度。

## 执行故障与核验

初次运行的96条训练均完成，但NumPy布尔资格标记导致SELECTION写盘失败。旧错误和部分JSON字节完整保留；另冻接续方案，只从同一TRAINED继续。**96/96原选择完全一致，原评分矩阵最大差0，未重训或重采数据。** 同一验证prior及参考积分的重放成本另计，不能写作零执行失败。见EXECUTION_REPAIR.md。

576/576优化运行报告收敛，实际21536次训练目标/梯度调用；全部96数值参考资格和独立36模型/9个梯度核验通过。核验是本地不同表达式复算，不是外部专家复现。

## 后续决定

本研究不足以完成更强的实践危害主张。固定预算不追加重复、seed或阈值。已完成的高预算近参照边界有使用意义，但仍缺少有区分力的自然数据决策结果。用户要求继续取得实质进展，因此另冻USE-v3公开二元图像流程，保留官方独立测试集，不用新结果追认本研究未通过的门。
