# REC-v2 失败、未决与保留边界

2026-10-05。反向结果属于本轮证据，不改倍率、seed、阈值或预算追门。

- **SCALE2不是普遍恢复。** 每初值14个风险差读数负、2个正。NEAR流03/12分别恶化约6.07e−5/7.50e−6，UNIT流02/14分别恶化约0.00179055/0.00052404。描述性计数不保证每项数值都跨越预定风险分辨阈，也不是逐输出同时推断。
- **总体有限目标不支持尺度候选。** 两初值、保留/消去模式的四个F_P均上升，虽然平均风险下降。NEAR保留F_D上升，UNIT保留F_D未决；消去后的F_D下降。不能将某个目标愿接受的候选推广到全部自由度。
- **MU_SAFE没有通过风险幅度门。** 32个经验观察NLL数值下降，但NEAR/UNIT平均风险变化+4.57e−7/−2.79e−6，都没有跨过−4e−6门。四个条件有限F_D方向未决；经验下降不保证风险或有限目标下降。
- **16/16精度通过仍有5项方向未决。** 冻结SE门衡量绝对精度，不能保证微小效应可辨；未追加MC。
- **能力界不能证明无法获得实用收益。** 189/192个输出对超界、32/32输出不能精确匹配教师，但保守KL下界均小于真实产品风险。剩余3对未被此界排除不代表可同时实现。
- **没有历史因果结论。** 当前尺度限制、当前有限目标偏好、梯度噪声/Adam/坐标/早期压缩不是同一个命题。本轮不能给出唯一风险原因或普遍修复方法。

制造资格初次通过后，冻结前复核发现预算表只计了基点的192次能力界，遗漏源码中SCALE2的同样192次确定性算术；同时补上显式的一维/四维边际及均值步数值下降标记。旧冻结、资格和修改说明保存在新包`PREEXECUTION_*`记录中。那时真实面板尚未执行，未增加候选或随机评价预算；最终资格重新通过后只运行一次真实面板。没有真实执行错误、科学重试或隐藏失败。

GH一致性和不同计算表达式不是严格余项证书；理论均值下降针对精确梯度，本次使用GH24近似梯度并另核实际步。旧MU固定0.05失败、原共同尺度包5/6制造资格及3/6方向门保持原字节，新资格不能追认它们。
