# 有效尺度的能力界与有下降控制的均值步

本页为新面板计算前的解析推导，2026-10-05。碰撞与原训练历史不是本页结论。Price恒等式与光滑下降方法为标准工具，不声称其本身是新理论贡献。

## 1. 固定尺度的自旋协方差上界

令Y_i|Z_i独立服从Bernoulli(σ(Z_i))，S_i=2Y_i−1，Z_i=μ_i+s_iG_i；Gaussian相关C满足diag C=1、C≽δI。由2×2主子式，|C_ij|≤1−δ。条件自旋均值是f(z)=tanh(z/2)，0<f'(z)≤1/2。对相关参数ρ使用Price恒等式，

\[
\frac{d}{d\rho}\operatorname{Cov}(S_i,S_j)
=s_i s_j E[f'(Z_i)f'(Z_j)],\qquad
\left|\frac{d}{d\rho}\operatorname{Cov}(S_i,S_j)\right|\le s_i s_j/4.
\]

ρ=0时协方差为0，且边际不随ρ变化，故对任意均值

\[
|\operatorname{Cov}_Q(S_i,S_j)|\le b_{ij}(s):=(1-\delta)s_i s_j/4.
\]

这是整个允许相关类的能力上界，不是实际C产生的协方差，也不是其可同时达到的保证。超过教师协方差不说明能够表达教师；低于教师才排除该对的精确匹配。只固定尺度、放开均值也不能突破该界。

## 2. 不要求边际相同的保守KL下界

对任意两个二元对分布P、Q，记T=TV(P,Q)。沿P_t=(1−t)P+tQ，Bernoulli协方差导数是对signed measure Q−P积分h_t(x,y)=(x−m_x(t))(y−m_y(t))。h_t在{0,1}²上的振幅不超过1，因而|Cov_P(Y_i,Y_j)−Cov_Q(Y_i,Y_j)|≤T。自旋协方差差不超过4T。

结合自然对数的Pinsker不等式及KL的数据处理，若d_ij=(|Cov_P(S_i,S_j)|−b_ij)_+，则

\[
KL(P\Vert Q)\ge KL(P_{ij}\Vert Q_{ij})\ge2TV(P_{ij},Q_{ij})^2
\ge d_{ij}^2/8.
\]

可以取六对下界的**最大值**，不能直接求和。该界适用于任意候选均值，避免将不同边际的协方差差直接当成KL。它可能很松；下界为正只排除精确恢复，若低于真实产品风险，不能据此排除超过产品基线或量化全部风险份额。本轮教师使用已冻结数值PMF，连续教师的严格求积余项仍未建立。

## 3. 均值经验NLL的曲率上界

固定任意协方差Σ，写Q_μ(y)=E_G f_y(μ+AG)，a_y(z)=y−σ(z)，B(z)=diag(σ(z_i)(1−σ(z_i)))。按f_y加权的Gaussian后验期望记E_y。平移参数求导得

\[
\nabla_\mu[-\log Q_\mu(y)]=-E_y a_y,
\quad
\nabla^2_\mu[-\log Q_\mu(y)]=E_y B-\operatorname{Cov}_y(a_y)\preceq\tfrac14 I.
\]

经验标签加权保持该上界。于是沿凸均值盒，经验NLL满足ell(μ+d)≤ell(μ)+gᵀd+||d||²/8。投影步μ⁺=Π_[-2,2]^4(μ−4g)满足gᵀd≤−||d||²/4，故精确梯度下ell(μ⁺)−ell(μ)≤−||d||²/8。

这一结论只针对观察似然的经验目标，不是有限K目标，也不保证教师风险下降。若实际使用近似梯度g_hat，右侧还须加(g−g_hat)ᵀd，不能把GH24当作精确梯度证书。本轮复用REC1已保存的GH24经验梯度，另用候选高阶PMF检查有限步实际变化，保留数值不确定性。

## 4. 保持观察边际的尺度变化

q(μ,s)=Eσ(μ+sG)对μ严格递增，μ从负无穷到正无穷时q从0到1。给定0<q0<1及s'>0，存在唯一μ'使q(μ',s')=q0。这保证对任意新尺度可保持一维观察边际，但有限μ盒未必可行。

本轮固定s'_i=min(2,2s_i)，保持C、tau，并在[-2,2]内解均值补偿。若某维不可行，完整尺度候选登记为不可行并保留基点占位，不以另一倍率替代。可行时改变的是依赖表达幅度；它不是旧μ不变的放大，也不是新的数据生成律。当前C符号或强度不合适时，放大可能伤害风险，不能预先承诺成功。
