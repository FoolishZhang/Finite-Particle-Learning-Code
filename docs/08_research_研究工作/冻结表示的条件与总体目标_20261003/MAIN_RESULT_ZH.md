# 残余目标倾斜与条件优化余量同时存在

固定旧16个FREE模型及原数据，使用32个全新MC组区分原数据条件目标F_D和参考总体目标F_P。本轮不继续训练；TAIL用于部署解释，LAST用于条件切片诊断。区间条件于冻结panel和数值总体权重，是MC开发t近似，不是新的训练总体确认。

观察风险属于积分模型Q，粒子准则属于随机K预测器；以下“错误候选”按前一个对象判断，不是否定log评分适当性或认定软件错误。

在四active、256独立公平无关位的固定构造中，t是六个潜相关的共同幅度增量，t=.3表示幅度乘1.3。冻结TAIL尺度下，该错误候选相对truth的总体评分差为−.0001095233，原共同区间[−.0001629567,−.0000560900]排除零；其参考观察KL为+.0002660636。同K FACT的候选差为+.0002052152，因此额外无关表示并非只增加参数无关常数，仍在改变正确参数的排序。

将真实256维尺度向量减半，候选差成为+.0001516750；由原P1与P3共同区间保守相加，范围[.0000533434,.0002500066]，这一对候选恢复为偏好truth。它不是全曲线、极小点或原训练自动恢复的结论；公平观察位仍保持概率1/2。

对实际LAST，只用前16组选固定grid比较点、后16组独立验证，得到平均F_D改进.0000488999，区间[.0000395862,.0000582136]。这确认冻结尺度的一维条件切片仍有平均可改善性，不是每个model或连续全局最优判断。

两个问题因此并存。还需区分准则与风险：已选诊断候选的事后平均参考KL为.0003554063，原LAST为.0002955851，7改善/8变差/1相同。这不是新风险检验或继续联合训练的预测，不能把条件分数更低当成风险必然更低。

四个预定评估效应与SE门均通过，2304次原API数值控制及参考资格通过；旧训练非劣失败不追认。原API32仅作限定数值资格，主曲线是理想数学准则的数值MC评价。v5.1继续封存。
