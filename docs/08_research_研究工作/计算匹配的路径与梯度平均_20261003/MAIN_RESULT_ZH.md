# 相同预算下的风险与粒子目标排序分离

在四份固定旧数据上，各使用16个全新prior四元组，以相同四份K100输入与原概念评分调用数比较两种程序：IN4在单路径内平均四份梯度后作一次更新；OUT4独立训练四条单bank路径，再平均最后64步的物理参数。

OUT4平均观察joint KL为.0026813001，IN4为.0058173972。OUT4−IN4差−.0031360971，训练q3/alpha.025共同开发t区间[−.0044855750,−.0017866193]。然而，对实际输出的独立评价，原raw D/P分数差分别+.0018194682/+.0016976662，独立q2/alpha.025区间均严格为正。**同采样和评分预算下，风险较低的输出反而受到原有限粒子目标惩罚。** 评价区间条件于冻结输出；训练结论条件于四份旧数据，不作新数据总体保证。

条件参数离散和条件均值误差的点估计均下降，但原q3区间仍跨0，不能追认。全部5项SE达标，训练方向只1/3分辨，评价2/2。OUT4平均风险接近不训练单位阵I的.0027110543，尚未确认优于I；I比较仅事后描述，无新检验。

本轮有320个低维优化程序、0新观测/神经网络。两策略各131,072次训练API，但Adam/修复次数为32,768和131,072；不称总成本或时间相等。OUT4是参数均值模型，非预测混合，不占参数平均首创。本轮支持风险与目标分开评价，未证明目标纠偏、最优预算或实用恢复。
