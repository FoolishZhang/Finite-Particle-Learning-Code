# R02FiniteScale-v1：结论、证据与尚未解决的问题

2026-10-10。固定对象是 `m=3, μ=0, C*=I, K=100, C=C(.45)` 处的单个自由相关导数 `D_n=∂c12 F_{n,100}`。本轮完成了一个严格的固定 K 二阶结构及其模型常数认证，并明确证明两种指定的粗误差预算在预定有限范围内无法判定领先负号。**尚未取得可用的真实有限余项 `E_n`，不能据此认证任一个所列有限 n 的梯度符号。**

## 1. 新取得的二阶结构

设 `L=log σ(G)`、`v=Var L`、`κ3=E(L−EL)^3`，`G` 标准正态。对固定标签和一个活跃候选粒子，令

\[
A_y=\sum_{i=1}^3\log\sigma(y_iX_i),\qquad
H_y=y_1y_2\sigma(-y_1X_1)\sigma(-y_2X_2),
\]

\[
m_H=E_YE_XH_Y,\qquad
\bar c=E_Y\operatorname{Cov}_X(H_Y,A_Y).
\]

`Y` 是均匀八标签，与候选 Gaussian 粒子独立。记 `J_K=E max_{k≤K}G_k`、`B_K=E[(max_{k≤K}G_k)^2]−1`。本轮证明

\[
\boxed{
D_n=-\frac{m_HJ_K}{\sqrt{nv}}
+\frac{B_K}{nv}\left(\frac{m_H\kappa_3}{3v}-\bar c\right)
+O_K(n^{-3/2}).}
\]

证明见 SECOND_ORDER.md (historical reference not distributed) 的 (S1)–(S18)：从精确标签内平均核出发，保留中心化 Gumbel；用 `log σ(G)` 的 Schwartz 密度及三段 Fourier 控制取得 `L1+L∞` 的密度、密度导数余项；活跃得分先中心化，共同平移精确消去；标记—得分协方差保留在 `n^{-1}` 阶。Price 身份进一步给出

\[
m_H=\frac12\partial_{c_{12}}E_Y\operatorname{Var}_X A_Y,
\qquad
\bar c=\frac16\partial_{c_{12}}E_YE_X(A_Y-E_XA_Y)^3.
\]

因此次阶不仅涉及 nuisance 偏斜，还涉及活跃得分第三中心矩随自由相关坐标的变化。上述导数不是三条边一起变化的等相关路径导数。结论限定固定 K；余项常数及有效起始 n 未显式化，不外推原主定理的整个增长 K 范围。

## 3. 两种指定有限预算在主要范围内明确失败

[METHOD_BUDGET.md](METHOD_BUDGET.md) 固定了两种误差上界配方，没有按结果重新选择 n。

第一种沿用全银行活跃得分事件和统一条件核误差，将真实噪声核到 Gaussian 平移核、Gaussian 平移核到未平移参考分别取非负上帽后相加。较小截断半径使事件外预算过大，较大半径则容许足以破坏统一相对精度的得分平移。即使把噪声近似误差免费置零，后一个障碍仍在。

第二种先固定标签平均活跃粒子，但将标记耦合改用绝对矩 Cauchy 上界，并以 `||g_n′||∞≤||φ′||∞+δ_n′`、`δ_n′≥0` 作三角帽。即使把 `δ_n′` 免费置零，标记项预算也已大于领先信号。

| 主要 n | 条件核配方 `η_min/m_H` | 平均核配方的标记预算 / 领先信号 |
|---:|---:|---:|
| 256 | 50.5111453 | 8.45903363 |
| 1024 | 31.8947996 | 4.22951682 |
| 4096 | 11.5277655 | 2.11475841 |

所有比值均严格大于 1；后续添加非负误差项不能使这些配方通过。平均核配方仅使其标记项小于信号就至少需要 `n>n_floor`，其中 `n_floor≈18318.143995999`，整数 n 因而至少为 18319。这是**该指定配方**的必要条件，不是任何方法的必要样本数，也不是实际梯度误差的下界。本轮没有增加 n 去追这个门，更没有据此断言有限尺度判向不可能。

## 6. 当前终点与后续判断

当前在“固定 K 新次阶结论 + 严格模型常数 + 两种明确方法瓶颈”处收束。下一步有价值的目标是，保留已识别的符号和协方差抵消，显式控制剩余项，争取在预定有限范围得到可用上界；重复评分 `D_n` 或继续缩小其 MC 区间不能替代这一步。

待外部审查判断的实质内容是：固定 K Fourier 范数论证是否足以支持所报余项阶；标签内中心化和 Price 转录是否保留了同粒子耦合；两种方法失败的范围是否准确；在没有显式余项的情况下，二阶结构及常数是否值得作为后续稿件增量。当前不声称已有有限尺度适用定理，不自动推进 R03。v1.9 和原科学封存保持；本轮没有生成 v1.9.1，也未将 R02 自动写入论文。
