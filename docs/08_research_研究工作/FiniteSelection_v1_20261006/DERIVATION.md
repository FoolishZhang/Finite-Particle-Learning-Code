# 条件方差与有限区域证书：作者推导

本页记录本轮新增解释与有限计算所用界。经典工具为Price、Pinsker、矩阵平方根的Sylvester方程和经验Bernstein界；不把这些工具本身列作原创理论。

## 1. 势函数的条件方差身份

令A_C(y,Z)=Σ_i log σ(y_iX_i)，T(C)=E_Y Var_Z A_C(Y,Z)，Y服从原固定教师。对每个y，E_Z A_C只依赖固定Gaussian边际，与C无关。非对角自由坐标c_ij的Price导数为E[∂_xi∂_xj A_C²]=2E[∂_xi A_C ∂_xj A_C]。再对Y平均，由原mark均值恒等式得到

∂_cij T(C)=(κ_ij(C*)+κ_ij(C))/2，故V(C)=−[T(C)−T(I)]/2。

Gaussian包络控制A及其导数的二阶矩，允许交换求导/积分。这个T是给定活跃观测的活跃log似然条件方差，再对教师平均；不是无关总log权重方差，也不是梯度方差。数值检查只作辅助，证明本身解析成立。

## 2. 低风险区域的可计算外包

以下固定本轮m=3、μ=0、C*=I、δ=.1。真实P在8模式上均匀。Price与log cosh u≤u²/2给κ'(c)≥β=exp(−1/2)/4；κ(0)=0。对f(y)=y_i y_j，Pinsker给|κ(c_ij)|≤sqrt(2R(C))。因此R(C)≤r0时，每个|c_ij|≤sqrt(2r0)/β，且

||C−I||F≤d=sqrt(12r0)/β。

取r0=10^-6，则d=.02284535206697714<1。沿I+t(C−I)，最小特征值至少λ=1−d。

## 3. 对全部低风险矩阵同时成立的分数下界

给定任意数据频率q、任意保存的先验Z_bk和正无关权重a_bk，定义φ_y(X)=−log Σ_k a_bk exp[Σ_i logσ(y_iX_ki)]。去掉的无关公共常数不影响选择。对所有X，||∇φ||≤sqrt(m)，||∇²φ||op≤m+1/4；后一项由加权发射Hessian及log-sum-exp梯度协方差的三角界得到。

S(t)=sqrt(I+tD)，D=C−I。SS'+S'S=D；SS''+S''S=−2(S')²。因此

||S'||F≤||D||F/(2sqrtλ)，||S''||F≤||D||F²/(4λ^(3/2))。

令a_b²=Σ_k||Z_bk||²。链式法则给每个银行、每个标签的二阶方向导数绝对值至多H_b||D||F²，H_b=(m+1/4)a_b²/(4λ)+sqrt(m)a_b/(4λ^(3/2))。对银行/标签平均并用Jensen得Hbar≤(m+1/4)A2/(4λ)+sqrt(m A2)/(4λ^(3/2))，A2是a_b²的样本均值。

经验非对角梯度g的对应对称矩阵Frobenius范数为||g||2/sqrt2。Taylor积分余项于是给整个G_r0：

Fhat(C)≥Fhat(I)−||g(I)||2*d/sqrt2−Hbar*d²/2。

如果该下界严格高于Fhat(Cb)，则任何分数不差于Cb的输出均在G_r0之外。无需推断网格分辨率或连续全局最优，也不必用风险选择候选。本文学习器的区间比较安全规则保证后一项。

## 4. 总体审计与概率范围

固定P均匀使F(C)=F(D_s C D_s)对所有对角符号矩阵D_s成立，故∇F(I)=0。Ea_b²=Km=6，Ea_b≤sqrt6给Hpop和F(C)≥F(I)−Hpop*d²/2。本轮此代价为.00158844598226789635。

独立银行只估g=F(I)−F(Cb)。耦合平方根并利用log-sum-exp Lipschitz性质，有|D_b|≤sqrt3 A max_k||Z_bk||，A=||sqrt(Cb)−I||op。截断六个Gaussian坐标于T=8，|D_trunc|≤M=3AT。Cauchy加Mills界给|ED−ED_trunc|≤sqrt3 A sqrt(6×12 φ(T)/T)。原合同的两项双侧经验Bernstein区间经union组成99% family；正的g下界减总体代价即为区域分离下界。

总体区间依赖iid Gaussian积分模型和已披露数值资格。它不是对所有积分节点的球算术证明；经验区域证书则对全部保存训练银行重算，二者不能混称。

## 5. 实现与数值根误差

候选C的条目按整数/10解释，谱底可行性用C−.1I的整数主子式核验。Arb把保存binary64数组作为精确输入。对对称正定的计算根S0，残差R=S0²−C给||S0−sqrt(C)||F≤||R||F/sqrtδ；分数误差因此至多sqrt(m A2)||R||F/sqrtδ。正定性用Sylvester主子式的球算术符号确认。区间内I、Cb、实际输出和I梯度全部重算；输出等于Cb时不将相同区间相减的非零宽度解释为真正的比较不确定性。

本研究证明的是指定有限程序在保存输入上的低风险排除，以及经限定概率/数值条件的有限总体分离。n0控制也通过排除，所以没有证明新增无关维度是这一实例失败的必要原因；没有证明一般Adam或所有全局极小点的实际风险都等于所选点风险。
