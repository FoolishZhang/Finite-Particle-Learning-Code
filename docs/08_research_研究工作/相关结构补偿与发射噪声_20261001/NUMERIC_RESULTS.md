# NUMERIC：固定相关结构与补偿候选的完整结果

六个固定模型在三个维数都通过原定数值资格门。补偿候选的联合 KL 从 d16 的 7.37697e−8 降到 d256 的 2.74462e−10；固定 R、尺度降到 (1,1) 的 KL 仍约 .013。补偿使用教师已知参数，是表示能力的 oracle 构造，未做学习或极小点搜索。三个维数呈现与 d⁻² 相符的描述性趋势；这些点不能独立证明最优收敛率。

教师是正相关、零均值、两已知等大组、尺度 (6,2)，rho=.9/(d−1)。五候选尺度均为 (1,1)。fixedRfloor 保持教师 R；comp 的两组载荷为 sqrt(rho) alpha(s_g)/alpha(1)；half/over 为其 .5/1.5 倍；independent 为零载荷。所有模型仍是一个 Gaussian 潜变量加条件独立 Bernoulli 发射。

## 噪声常数、资源与审计

tau_a²=2 alpha(1)=0.826483857，负教师总自旋极限方差 V*⁻=0.57757087，差=0.248912986。这里的负教师与上表正教师不同。alpha 沿用旧已合格 GH2048 主值，GH1024/quad 敏感性原样保留，0 新 alpha 积分。tau_a² 不能再平方。

原生产工作为 18 主 PMF、72 积分变体、270 固定 z 检查（正负概率合计 540 次 scalar quad）、15 次 Decimal80 候选 KL 核验，三维数记录耗时合计 24.848 秒；0 新观察、随机粒子、拟合。独立审计的额外确定性积分和核验另计，不重复算作新科学模型。

NUMERIC 最终独立审计通过。首次审计因 NumPy boolean JSON 序列化中断，保留 FAILURE.json (historical reference not distributed) 与不完整收据；这是审计写出故障，不是生产数值门失败，原冻结和数值规则未改。
