# R02Remainder-v1：一个明确有限规模的梯度负号

2026-10-10。固定第一模型 `m=3, μ=0, C*=I, K=100, C=C(9/20)`，`D_n=∂_{c12}F_{n,100}` 是单个自由相关坐标的总体导数，n 是 nuisance 坐标数。

本轮得到显式有限不等式

\[
|D_n-D_n^{(2)}|\le E_1+E_2+E_3+E_4+E_5,
\qquad
D_n^{(2)}=-\frac{m_HJ_{100}}{\sqrt{nv}}+\frac{b_2}{n}.
\]

在原有四个规模中，**n=4096 首次由这一有限理论界认证负号**：

\[
E_{4096}<0.000846727778,\qquad
\boxed{-0.002045393<D_{4096}<-0.0003519373<0.}
\]

这是明确有限 n 的总体数学梯度结论，不依赖旧 MC 置信区间。它也不是直接积分 D4096 得到的新点估计：本轮认证噪声函数和比较权重，再经解析传播包围真实导数。所有显示外包端点在交付检查中按精确有理数核对。

## 此前缺口如何闭合

1. **真实有限噪声。** 保留中心化 Gumbel，认证标准化 log-sigmoid 的第四矩及273个特征函数值。低频使用显式四阶 Taylor 余项，中频用有限节点和 Lipschitz 帽，高频用变量变换得到的显式 BV 尾。密度、CDF、导数及 Sobolev 范数均有可计算上界，未留下未知 Cramér 常数或有效起始 n。
2. **保留极值权重。** 分部积分把 `F^98` 的权重留在 Gaussian 比较积分中；用真实正密度同伦控制二次余项。没有把有符号 Edgeworth 截断当正密度，也没有除以尾部很小的实际密度。
3. **活跃部分不再新增积分。** 精确两标签类约化仍对应自由 c12。类协方差、四阶矩上帽由旧严格常数、Price 身份、Gaussian 分部积分和 Poincaré 不等式闭合。`M2<0.307468813` 是误差用上帽，不能当作真实矩值。

完整证明见 FINITE_PROPAGATION (historical reference not distributed)、Fourier 推导 (historical reference not distributed)及[执行误差方法](NOISE_CERTIFICATE_METHOD.md)。生产使用的频率下限为1/4，规划中先前的1/2方案没有执行；最终参数和源码都在查看本轮生产结果之前冻结。

另有分位数加权接口 (historical reference not distributed)及其窗口外 `<1e−5` 解析尾界。这是独立备选表达；当前五项预算已覆盖整个实轴，**没有再叠加该尾界，也未计算分位数窗口内部**。

## 新计算与核验边界

- 主噪声：385个 Gaussian 节点、105105次复指数、547个实标量有限和，约0.322秒。
- Gaussian 比较权重：3073个保存节点，约0.069秒；16个比较积分由单调端点和与解析尾形成严格包围。
- 独立普通 GL384/512：896节点、244608次复指数，核全部273个复 CF 和第四矩，约0.075秒。CF分量距严格区间最多约3.05e−14，两阶差最多约3.55e−15。该项是独立表达一致性核验，不是第二份严格求积证书。
- 另有保存端点 Fraction 算术、制造夹具和作者逐项解析核对；检查程序不形式化验证整篇数学证明。
- 0新直接 Dn 评分、0新随机样本、0训练/优化、0科学 NPZ 读取。以上确定性计算确实发生，不能把本轮概括为“0新科学计算”。

生产噪声、权重和独立积分各运行一次，均在预定预算内完成；四个规模全部报告，未加大 n 追门，未根据旧 MC 值缩小误差。

## 结论范围与合理收束点

只认证固定模型、固定K、固定相关点和自由c12坐标上的4096负号。没有给出所有n≥4096、最小阈值、渐近近似10%精度、教师族、训练轨迹或增长K的一致保证；也没有更改旧面板的统计/数值资格。此结果加强 R02 的有限桥接，但不替代原一般渐近定理或 R01 完整空间局部见证。

当前在完整有限传播和一个非空判向实例处收束，保留未过门部分，供用户安排科研审查。v1.9、旧R02和旧科学证据保持；暂存三项写作建议与R03不执行。后续优先检查证明的高影响步骤及入稿价值；若继续收紧，我倾向先针对1024的E2/E3结构，而不是立即增加规模或重跑旧实验。
