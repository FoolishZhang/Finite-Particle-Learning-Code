# 作者结论：真实F8驻定残差已闭合，完整Hessian仍待认证

本轮取得的实质结果是：**原固定中心的真实F8完整24维梯度L2范数<7.572×10⁻¹⁰。** 这包含有限域求积、尾部、教师目标和区间算术误差，通过事前的10⁻⁸门；不只是保存浮点梯度很小，也不是靠两档规则一致性推断误差。

## 1. 41类计算保持完整教师权重

在零偏置且反序成对行长相等的中心，A和四个正交方向score只依赖paired count c∈{0,1,2}⁴；先验反射又使c与2−c的梯度相同，因此81类归为41代表。原256个教师概率严格求和成类权重，没有假设类内等权、没有用重数代替真实概率，也没有归一化。

计算的坐标是ξ_j=√2 a_j，对应物理单位方向(e_j+e_(7−j))/√2。精确教师的偏置/反序与潜变量反射对称性给出其余梯度为零，从而完整24维梯度范数等于该四维范数。这个提升用于最终精确教师结果；不能仅凭任意有限目标的四维梯度就作同一结论。
