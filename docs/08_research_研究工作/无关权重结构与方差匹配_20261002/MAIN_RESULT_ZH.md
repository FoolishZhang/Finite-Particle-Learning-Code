# 同统计任务、同对数方差，仍可得到相反的相关学习

**总log权重方差不足以决定无关扩展会不会破坏相关学习。** 本轮构造了积分观测分布、无关维数、总对数权重方差及粒子预算均匹配的Gaussian-logistic表示：分散噪声仍诱导错误相关；集中噪声可使同一raw粒子目标恢复精确统计任务。这里改变已知的、与待估参数无关的无关发射尺度，没有新增目标修正池。

设active相关尺度为1，候选rho∈[−R,R]。n个独立无关坐标无论采用什么已知正尺度，其观测都为公平位，因此精确Q及active joint KL保持相同。令v(a)=Var(logσ(aG))。diffuse族取全部a_i=1；有界异质族取固定正紧区间内的尺度；集中族取n−1项1/n和一项A_n，使

\[
v(A_n)+(n-1)v(1/n)=n v(1),\qquad A_n=\Theta(\sqrt n).
\]

对数权重的均值只给候选无关平移；将三族各自居中后，均值均为0、方差仍匹配，softmax和参数比较都不变。

**错误方向在有界异质类中仍稳健。** 对任何确定尺度数组a_i∈[a_-,a_+]，0<a_-<a_+<∞，相对局部密度及尾估计可统一推广到非同分布三角阵。归一化raw梯度仍趋向−[r(θ)+r(ρ)]/4；令s_n²=Σv(a_i)，在2≤K≤C n^p下，regret为o(J_K/s_n)的总体近优点趋端点，内点真参数保持正积分风险。

**集中族具有另一种权重几何和恢复路径。** 归一无关权重W_n满足EW_n=1、EW_n²一致有界、||logW_n||₂=O(√n)。由对数误差界，K=n+2时raw总体目标减nlog2后统一恢复精确active交叉熵。事先固定的有限网格逐渐加密、含两端点且大小O(n^1/4)，N任意预定发散时，真实完整观测的精确网格ERM甚至在B=1也一致。与diffuse取同B=n、同数据、同K、同网格时，两种精确网格ERM分别有零与严格正的极限joint期望风险（真参数固定在内点）。

几何上，集中权重在合适耦合下L²趋向2·1{G>0}；K也增长时，noise-only ESS/K趋1/2。分散及有界异质族则ESS趋1、最大归一权重趋1。都是概率结论；完整active权重还会变化，ESS不能替代对数尾控制。

恢复的充分条件已推广到固定有限active观测字母表及紧SPD Gaussian-logistic类，故不依赖单一经验相关矩。另给四变量、六相关参数盒的错误总体方向和正风险对照；该多参数负侧尚未证明实际共享bank学习预算，不与正侧拼成多参数有限数据分离。
