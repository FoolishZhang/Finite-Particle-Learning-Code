# 六变量严格证书如何用于更多变量

本文件只组合本轮已经完成的证书与条件化闭合性，不新增拟合或随机样本，不改J/Q/M的冻结或主判定。普通RC均指单个、无符号、无隐变量混合的一元势加laminar子集count势模型；所有query共享同一个joint。对有限实势不设幅度上限，取其闭包也不降低以下下界。

## 1. 条件化后仍是普通RC

固定一个六变量真块B和其补集配置z。一个RC因子原来读取集合S的count；条件化后读取S∩B的count加固定偏移。交集族仍laminar；空交集给常数，重复交集可合并，其余可补成满二叉树并把新增势设零。因此Q(C_B|z)属于六变量普通RC，由945棵带标号满二叉树覆盖。条件化可以改变势，却没有读回块内被count压缩的身份信息。

## 2. Joint证书只给常数下界

令J_*是J证书 (historical reference not distributed)的严格下端。若P=P_0.9(C_B)P(C_-B)，KL链式法则给

\[
D(P\|Q)=D(P_{-B}\|Q_{-B})+
 E_{P_{-B}}D(P_{0.9}\|Q(C_B\mid C_{-B}))\ge J_*.
\]

J_*约为0.049063732043350761。加入独立坐标或更多独立块均不使这一常数失效。不能对不同B把这条式子相加后声称mJ_*：完整补集条件KL没有这样的可加保证，多块证明 (historical reference not distributed)保留了反例。

## 3. 平均全坐标LOO证书可以按块平均

令Q_*为[Q的160bit证书](../../../artifacts/rc_quant/Q/SUMMARY.json)的严格下端，约0.029099056357852163。对每个固定z，块内六个目标均匀平均的LOO风险就是同一Q(C_B|z)上的六变量目标，所以至少为Q_*。再对z和真块平均即可。

特别地，D=6m且所有块的|epsilon_b|=.9时，对均匀抽取全部D位的目标和其余D−1位证据，任意普通RC有

\[
\mathcal R_D(P,Q)\ge Q_*.
\]

这不是固定六个目标的保证，没有6/D稀释。负epsilon通过交换一个真pair的两坐标转换为正epsilon；坐标置换保持普通RC类，因此同一常数适用。

M实验一半块的绝对幅度为.75、另一半为.9。对前者使用解析摘要界 (historical reference not distributed)delta(.75)=3/2560，对后者使用严格Q_*，得到另一个组合结论

\[
\mathcal R_D(P,Q)\ge\tfrac12(3/2560+Q_*)
 \approx0.015135465678926.
\]

这是M完成后的证书组合解释，不是M的事前主门。原主门保持解析块平均87/56320，约.00154474431818；全部原判定与置信家族不变。更强下界不改变M低样本恢复失败的事实。

## 4. 为什么不把下界当成一条实验曲线

这些是指定教师族对整个普通RC表示类的风险下界，不是实际运行过的D维RC训练基线，也没有RC训练耗时。MOM、MLE及clique histogram属于不同表示类；它们跨过下界说明该结构信息能从数据学习，不证明本项目提出了新学习算法或端到端成本优势。Gaussian桥接另有自己的三变量下界，不能代入本文件的六变量常数。
