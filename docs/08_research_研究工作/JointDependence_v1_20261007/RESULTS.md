# 本轮实质结果与尚未解决的问题

本轮完成的是新研究而非改稿。八位观测共享二维Gaussian潜变量，全部偏置和8×2载荷由数据学习；teacher八行载荷均非零，所有非对角内积严格正，观察变量两两相关，因此不存在指定独立可删块。此前USE已做求积训练后选模，Tipping等文献也已有直接近似似然学习；模型与方法本身不是新意。

## 1. 有明确方向的解析接口

固定零偏置与行范数，写载荷为εv_j(φ)，c为未缩放载荷的非对角Gram向量。作者推导给出固定K的角度目标四阶项

\[
\varepsilon^4\{a_K\|c\|^2-b_Kc_*^Tc\},\qquad
 a_K=\frac{(K-1)(K-2)}{32K^2},\quad b_K=\frac{K-1}{16K}.
\]

真值处某方向若c_*·dot c>0，则目标导数首项为−ε⁴(K−1)c_*·dot c/(8K²)，而精确风险在真值处最小。预定角度压缩方向满足该条件；K1的角度不变是精确身份。证明给出了可积导数支配及独立K2系数核对，但没有显式ε适用阈值；新推导待用户组织科研审核。

确定性K2四维求积确认一个具体实例：ε=.25，角度压缩5%，保持全部一维边际，有限目标差为−.0000378093733，真实观察KL增加.00000220782999。该点跨阶目标差约2.22e-14、导数差1.02e-12。ε=.125也通过；ε=.5/.8的四维角度精度未过1e-7门，未追加阶数或改门。完整表与源码见[角度结果](ANGULAR_RESULTS.md)和[证明](PROOF.md)。这是数值资格，不是严格积分余项证书。

## 2. 实际联合学习与独立目标排序

预定4流各4096新观测；三臂各1200步，固定LAST读出。K8/K64每步共用128个二维prior向量，分别分成16/2个bank；GH使用二维求积经验目标。同参数类、同数据和初始化；基础粒子数相同不代表梯度噪声或总成本相同。另用GH40检查并求解REF，IND为同数据平滑独立拟合。

|程序|四流平均观察KL|相对解释|
|---|---:|---|
|K8|.011089462|四流都高于K64和REF；载荷近乎共线|
|K64|.002891623|相比K8均值下降73.9%，保留明显第二载荷方向|
|GH / REF|.002631361|GH已达到REF的梯度停止门，REF未再移动；不作全局MLE保证|
|IND|.107476910|所有联合程序都从数据中学到有用依赖，K8并非完全无用|

独立银行评价中，F8在每流的经验与总体标签下都估计偏好K8而非REF：总体差为−.01799到−.01989，条件MCSE约.00039到.00087；精确经验NLL与真实KL却都偏好REF。改用F64评价时，所有流的两类标签都改为偏好REF。因而问题不只是某次训练输出坏：固定终态之间存在目标排序冲突。[逐流数据](TRAINING_RESULTS.md)给完整正反例。

K8单位载荷的平均两两内积>.99996，归一Gram第二特征值为1.20e-5到2.30e-4；REF为1.34到1.60，K64为1.08到1.46。这是近一因子的载荷形状，不是原论文谱下界定理的验证，也不是观察变量只有一个随机维度。K8还同时收缩了行长，必须继续区分其作用。

这仅是固定教师和程序的4流探索，不宣称训练总体显著性或“稳定失败概率”。MCSE条件于已锁定终态，4096个评价银行不是4096个独立训练流。K64有两流风险略低于REF，不能把更精确积分写成逐例风险最优。

## 3. 固定边际的机制检验：有支持，也有限制

在训练结果出现前预声明H8/H64：保留REF偏置和每行范数，换入K8/K64学到的单位方向。使用另一批独立prior，没有teacher对齐或重新训练；全部候选在原box内，观察边际最大数值差6.67e-16。

H8四流KL都增加.01553到.01611，平均风险.01837642；H64平均.00304014。实际学到的依赖形状因此有独立于参照边际的风险代价，而且较大K的角度代价小得多。

**但是，H8−REF的F8偏好没有四流一致成立。** 经验F8在流3反向，总体F8在流1为正，若干差值与MCSE同量级。不能将完整联合终态的目标冲突机械分解成“任何固定边际角度变化都降低F8”；没有据此追加bank或改用有利中间角度。[完整profile表](PROFILE_RESULTS.md)保留全部结果。F64对H8仍一致给更高损失。

所以当前结论是：无指定可删块的联合学习中确有有限目标—风险冲突，并伴随可测的错误依赖形状；**纯角度机制仍不足以单独解释全部完整训练结果，行长/偏置/角度的耦合是下一缺口。** 零偏置弱载荷展开也不直接认证当前有限载荷、非零拟合偏置的训练终态。

## 4. 本地核验、勘误与范围

核心GH/MC梯度、银行边界、K1与旋转夹具通过。角度独立核验读取全部32份保存数组并抽查直接概率/导数；训练核验区分保存梯度下的全更新重放与少量独立梯度重算；profile另核参数移植、边际、全部保存评分统计及固定银行/求积点。具体覆盖量见相应审计收据，不冒称全部训练梯度或全部底层计算已独立重做。

审计发现四流路径摘要共16个theta字段存在可变视图别名，已用当时落盘的PATH文件和全轨迹补正；原始文件、失败审计、损失/梯度/资格及终态都保留。见[记录勘误](RECORD_ERRATUM.md)。不重抽、不重训、不放宽门。

新科学总计16,384条完整观测、14,400次Adam更新，以及2,711,552个训练/独立评价二维prior向量；另有确定性求积节点，按阶段单列。没有新增确认性置信家族，也不把这些探索结果并入旧96%/95%的封存家族覆盖。

本轮已经达到实质性进展，可以在此交用户组织科研审核。最值得审的是角度展开、当前结果相对Tipping/IWAE因子分析的实质增量，以及如何解释profile的不一致；不需要先扩大seed、教师或K矩阵。v1.5.1保持，后续是否改稿见单列提案 (historical reference not distributed)。
