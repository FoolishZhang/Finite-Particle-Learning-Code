# 官方联合评分接口中的排序反转与尺度边界

本轮直接调用未修改的官方SCBM `SCBLoss.compute_concept_loss`，在一个四概念、非零均值、正负相关混合的Gaussian-logistic fixture上，确认了独立扩展引起的有限候选排序反转。使用当前Torch2.5.1 CPU的原生float32路径，没有调用encoder、完整训练损失或优化器。

候选参数t控制全部六个潜相关的幅度：Σ(t)=I+(1+t)(Σ*−I)，真参数t=0，high候选t=.75将相关幅度乘1.75。均值和对角方差保持相同；它的完整观察joint KL相对真分布约为.001724195 nats，不随独立无关通道数n变化。t=.75不是一个相关系数等于.75。

16个独立流、65536条新完整观测、默认K100下，high-minus-truth评分为：

|无关通道|原API平均差|四项家族t开发近似区间|
|---:|---:|---:|
|0|+.00142404|[+.00082559,+.00202250]|
|256|−.00378112|[−.00645150,−.00111075]|

附加通道使程序平均偏好统计上更差的候选。truth处相关方向梯度的配对位移为−.00417546，共同区间排除零；四项原效应门和四项SE资格全部通过。它们是开发t近似，不是精确覆盖；stream6/7反向样本保留，不能说所有实现都反转。

这里的风险属于积分观察模型Q，而API优化随机K粒子预测器的平均log评分；结论是两种合同的偏好分离。

正确因子分解仍调用同一官方active API，并把已知nlog2作为候选无关常数处理，保持原评分对比与active梯度逐实现不变。它恢复扩展不变性，但固定K下仍可有active粒子偏差。辅助K400仅使用每流共同前1024条，点估计仍负但误差较大，不能确证增加K是否恢复排序。

实现与独立stable-logit64数值对照的288个分数、96个梯度资格均通过；主概率没有出现0/1饱和，最大|logit|约6.17。stable64包含输入/参数舍入及表达变化，并非官方第二dtype路径；前缀资格不认证全部浮点误差。

同时，实算术理论证明：对独立零均值nuisance块，任何有限K下，正尺度τ_i处的总体concept-loss偏导严格为正，且对正确分解的总体偏差在[0,Στ_i²/8]内。原API在τ=1测得的共同尺度梯度除以n为+.125835，与这条下降路径一致。没有训练尺度，不能称已学会修复。代码标准差floor的理想数学界也不是浮点精度承诺。

非零均值的Price方向涉及观察中心协方差之和；对原生0/1标签Y与spin S=2Y−1，truth标记为Cov(S_i,S_j)/2=2Cov(Y_i,Y_j)。新增逐观测私有prior桥：理想实算术、2≤K≤Cn^p、N/n→∞的精确三候选ERM趋选扩大相关端点并保留正joint风险；另外K_n→∞时，因子分解的三候选ERM恢复真参数。数值/求解误差须有相应控制，不能直接赋给固定float32或SGD。

本结果连接了原机制与实际评分代码，同时明确了可学习无关尺度的边界。它不构成完整SCBM训练失败、自然数据性能或全自由协方差优化结论；本次有界来源核查未找到合格官方checkpoint及配对数据，核查范围已如实记录。v5.1及旧科学保持。
