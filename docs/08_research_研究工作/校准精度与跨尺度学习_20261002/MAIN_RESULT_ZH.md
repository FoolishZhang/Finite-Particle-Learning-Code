# 可守的核心陈述

在已知两位相关块、a=1、固定0<R<1的Gaussian-logistic模型中，有限prior学习可在精确统计任务不变时被独立无关坐标扭曲。在n增长、K至少2且至多多项式增长、数据为独立于两prior池的正确指定iid完整观测时，新增定量分析将有限校准斜率b、目标误差与实际学习风险连接，并给出训练bank数B、独立Price校准bank数C的充分条件：Bw²→∞、Cw→∞，其中w=J_K/sqrt(nv)。配合N→∞、适当细化网格及精确已知r的实算术条件，完整joint风险趋零；不是必要阶、SGD或当前固定101/801实现的自动认证。

一个明确例子取K=n+2、B=n、C=ceil(sqrt(n))。校准与raw共用相同训练bank：校准估计趋真teacher，raw在非零内点teacher下趋向同号但幅度错误的端点，在零teacher下趋±R集合并保留正风险。附加校准bank相对较少，不等于同总成本或比已知结构MLE高效。

新的16个N4096完整数据流覆盖n62/254×K64/256，四项localquad相对fullfinite的teacher合并KL非劣门均通过，最大共同区间上界1.48227e−5<预定1e−4；完整校准对同数据MLE的合并参数MSE从B128的.00863918降至B512的.00219368，第五门也通过。区间为条件于冻结校准的开发近似，非逐teacher或全参数域保证。固定K256、null、B512时，n62→254使raw端点数0/16→16/16，而marg与MLE保持逐实现不变。
