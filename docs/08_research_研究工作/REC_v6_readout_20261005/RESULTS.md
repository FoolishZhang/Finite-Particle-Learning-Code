# REC-v6：LAST与TAIL的固定读出敏感性

**读出会改变MIXED同数据F400的微小平均排名：LAST略偏INNER，TAIL偏OUTER。但NULL和两个条件的总体F100/F400均仍偏OUTER，MIXED改善/NULL恶化的风险方向也保留。** 因此，TAIL可解释这一局部排名差异，不能解释全部目标—风险关系。

本轮比较同一批128条训练轨迹的LAST与原定TAIL，共256个读出。没有新训练或checkpoint搜索；LAST新增风险求积，四个模型状态共享新的独立评价粒子。主要问题是REC-v5的面板平均目标排名是否依赖TAIL平均。

## 5. 核验、预算与解释范围

主参考全部通过：True；独立GH44参考全部通过：True。24项MC中24项通过SE门，0项区间跨零。原轨迹提取、标签、全部262144bank的保存分数/Jensen及统计算术通过，最大差1.78e-15；2048个独立直接概率分数最大差2.66e-15。

主运行467.35秒；104857600个共享prior向量（419430400Gaussian），128个LAST的GH32/40/48共1141374976节点，8个独立GH44共29984768节点。MC审计另重放6400向量，不增加独立样本。TAIL原参考不重算，无新观察、训练或优化。

两读出属于相同旧轨迹，结果只能解释这个固定有限程序。新的MC区间不替代REC-v4训练流区间，LAST与TAIL风险读数也没有被包装成新的总体确认。没有挑选最优checkpoint或调整平均窗口；原科学结果及失败保持。具体作者判断与后续取舍见AUTHOR_UPDATE (historical reference not distributed)。
