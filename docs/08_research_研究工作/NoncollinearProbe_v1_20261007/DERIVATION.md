# 配对损失、偶性与保持边际的有限路径

本轮直接应用正似然的Laplace/Frullani恒等式，不把二维扩展称为新算法。模型、theta与K沿用设计 (historical reference not distributed)，原完整Hessian见[前轮推导](../RankOneStationary_v1_20261007/PROOF.md)。

## 1. 同尺度下的直接差额

对固定label y，粒子条件概率A_t(z)>0。固定正c_y，令x_t=A_t/c_y，S_t=Σ_{k=1}^K x_t(z_k)，则

\[
-\log(S_t/K)+\log(S_0/K)
=\int_0^\infty [e^{-uS_t}-e^{-uS_0}]\frac{du}{u}.
\]

在同一真实Gaussian先验下对独立K粒子银行取期望，独立性给E exp(−uS_t)=Ψ_t(u)^K。于是

\[
F_K(t)-F_K(0)=
\sum_y q_y\int_{-\infty}^{\infty}
[\Psi_{y,t}(e^v)^K-\Psi_{y,0}(e^v)^K]\,dv. \tag{1}
\]

只需单粒子二维Gaussian积分求Ψ，不需2K维银行求积。有限log-u区间与离散Gaussian节点是数值近似，(1)本身不提供截断余项证书。

离散normal测度ν总质量为M时，K粒子积测度质量为M^K。两端使用同一ν和c_y，−M^K log c_y及Frullani参考项恰好相消，所以直接差额仍是(1)的原测度版本。改变t时重新选不同scale然后忽略常数差是不正确的；本轮每anchor/rule使用同一个基线scale。

生产核对两个Ψ幂使用符号保持expm1差分；独立核验先由节点上的指数差获得ΔΨ，再用幂差恒等式计算。这两条浮点路线都只是数值计算，精度须用冻结的跨规则和独立核验确认。

## 2. 风险差

记p_t(y)=∫A_t(z)dν。在真实概率模型下

\[
R(t)-R(0)=-\sum_y q_y[\log p_t(y)-\log p_0(y)].
\]

教师熵相消，故该直接风险差与总体积分负对数似然差相同。程序保留raw ν和q质量，另报告PMF质量及绝对KL。不能把“有限F_K下降”替代为“风险下降”；二者均直接计算。

## 3. 精确保留一维边际与偶性

W_j(t)=a_j(cos(td_j),sin(td_j))，所以||W_j(t)||=a_j。标准二维Gaussian投影W_j(t)·Z与a_j Z_1同分布，因此每个观察的一维Bernoulli边际保持；联合分布可以改变。低秩/非共线说的是载荷结构，不是Bernoulli观察协方差本身的秩。

用共同反射Z_2→−Z_2把路径t映到−t，可见每个label的真实模型概率、有限银行期望损失与总体风险都为偶函数。制造和科学面板仍独立计算两侧，并核离散规则的边际及偶性残差。

本轮d不是常量向量，全部a正，且选定非零|t|≤.10时行角度差远小于π；因此这些非零路径点确实不共线。它们没有重新拟合b或行长，不是二维模型的优化解。

## 4. 与旧曲率的连接和限制

固定有限K时，对本模型log-sum-exp的局部参数导数可以用Gaussian多项式矩支配，故在t=0附近可作四阶Taylor展开。偶性消去奇数项：

\[
F_K(t)-F_K(0)=\frac{t^2}{2}d^\top H_\phi d+O(t^4).
\]

同样的风险式使用其补偿角度Hessian。本轮直接差额并非用这一公式生成；2Δ/t²与旧曲率的比较显示所选幅度上二阶近似的实际偏离。偏离较大可以是有限尺度项，不自动归为数值失败；差额资格和Taylor接近程度分别记录。

即使主幅度获得F11上升、F12下降、两端风险下降，也只闭合当前教师、固定方向的局部机制证据链。它不保证F12全局恢复、随机优化自动离开共线子空间、普适临界K或独立条件下的预测效用。第三档增强需要另行设计并冻结独立条件，当前不启动。
