# 非零已知均值下的全梯度与完整 Hessian 核

教师是Q_(I,μ)的独立乘积律，标签概率为∏p_i或1−p_i，p_i=Eσ(μ_i+X)。在对候选相关C求导时，这些教师概率固定。它们仅在关于μ的稳健性证明中随μ变化；两种微分不能混淆。

对固定y及一个银行，令x_ki=μ_i+Z_ki，q_ki=y_iσ(−y_i x_ki)，r_ki=σ(−y_i x_ki)[2σ(−y_i x_ki)−1]。q可有符号，r是单粒子似然的二阶相对导数。π是无关权重乘完整活跃似然后的归一权重。

相关对p=(i,j)的Gaussian Price梯度核为

G_p=−Σ_k π_k(1−π_k)q_ki q_kj。

令a_pk=q_ki q_kj，A_p=Σπ a_p，B_p=Σπ²a_p。Hessian对角项采用前轮相同多项式：

Σ[−π(1−π)r_i r_j+2π²(1−π)(q_i²r_j+q_j²r_i)+π²(1−4π)q_i²q_j²]+A_p²−4A_pB_p+6B_p²。

不同相关对在m3下恰好共享一个坐标。设p=(a,b)、q=(a,c)，则非对角项为

$$
H_{pq}=\sum_k q_{kb}q_{kc}
\left[-\pi_k(1-\pi_k)(1-2\pi_k)r_{ka}
+3\pi_k^2(1-2\pi_k)q_{ka}^2\right]
+A_pA_q-2(B_pA_q+A_pB_q)+6B_pB_q.
$$

证明来自−logΣw的四阶集合分割公式。对同一粒子，∂_(a,a,b,c)的原系数为q_bq_c[−π(1−π)(1−2π)r_a+π²(4−10π+6π²)q_a²]；把不同粒子有序交叉项求和后减去重复的同粒子项，就得到上式。μ≠0时不能令混合Hessian项为零。

固定标签下|q|≤1、r∈[−1/8,1]。梯度范围[-1,1]；对角仍在[-33/8,67/16]。非对角局部求和绝对值≤4。对每个对p，A_p和B_p符号相同，且|B_p|≤|A_p|≤1；交叉整体项可写成A_pA_q(1−2s−2t+6st)，s,t∈[0,1]，绝对值≤3。因此非对角范围[-7,7]。

最后将八个固定标签的梯度和Hessian按真实教师概率加权。只在银行之间作独立平均，八标签和两个条件都不是额外独立样本。完整矩阵的签名用同时覆盖的六个元素区间作Gershgorin认证，而不是只看三个对角元素。

多项式核通过直接Price算子与Arb计算核验，不用相关矩阵平方根路径的逐银行二阶差分来作相等性断言：两种估计器仅总体期望相同。K1时每粒子的log似然为三个一维项之和，所以所有相关Price导数逐银行都为零。
