# 当前可守的核心陈述

无关观测不改变精确统计任务，却能改变有限prior粒子目标的学习偏好。纠正平均目标之后，数据量和独立bank数仍控制不同误差：在a=1、R<1、K≥2的已知两位相关块Gaussian-logistic模型中，固定参数梯度方差精确分解为σ_Y²/N+σ_Z²/B+σ_e²/(NB)，且有限n/K时σ_Z²严格为正。故固定B，即使平均校准完全准确，无限数据目标的实际全局最优点仍有正期望joint KL。该结论限内点teacher与固定C¹罚项，不给实用下界或SGD保证，也不声称经典方差分解为新方法。

在固定a=1、n=254、K=256、N4096的16个旧完整数据流上，使用全新嵌套prior，将B从128增至512，完整有限校准相对同数据数值MLE的平均参数MSE从.00505094降至.00122021；差值的共同95%开发近似区间为[.00102831,.00663314]。另以独立8192bank、六个模型点估计单个二次系数c=.00837193；B512下它相对完整校准的teacher合并joint KL差为3.09282×10⁻⁶，上界6.71100×10⁻⁶低于事前容差10⁻⁴。两项新主门通过；旧四门2/4保持。

结果表明当前预算下无需复杂完整校准曲线即可获得接近的风险，而增加B对校准后的精度有实质帮助。合并teacher非劣不等于逐teacher或全参数域保证；这是同旧数据上的计算干预，区间条件于冻结校准，非新数据复制。本面板marg到同数据MLE的误差更小；给定现有r表时MLE计算更简单，未做端到端速度比较。本包不宣称通用算法优势，完整稿v4.1未改。
