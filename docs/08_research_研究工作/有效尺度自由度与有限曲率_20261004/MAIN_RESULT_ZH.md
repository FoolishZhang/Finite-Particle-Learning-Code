# 中文核心：有效自由度并不自动修复粒子目标的依赖偏好

在有效维数固定、无关块独立且以固定单位尺度表示的模型中，释放全部有效均值与尺度，不保证消除有限先验粒子目标造成的观察风险。其表现可以由固定尺度下的错误相关，转变为有效依赖被压平。

局部的精确判据是

\[
H_s=D-(1-\chi)(\Gamma\circ C),\qquad
\chi=E\sum_k\pi_k^2,
\]

其中π是仅由无关块构成的归一权重，D为观察边际方差矩阵、Γ为观察协方差。在全部C≽δI、diag C=1上，令B=δ+(1−δ)λmax(D⁻¹ᐟ²ΓD⁻¹ᐟ²)。当χ>1−1/B，产品边际在均值与尺度方向一致局部稳定；教师有非零两两协方差时，仍存在合法非负尺度激活，能降低观察KL却提高原评分。零尺度处C不识别；纯高阶依赖不能用该二阶条件判定。

全局上，紧参数类中的原目标与单粒子交叉熵之差由常数乘(1−χ)控制。沿单位无关尺度、多项式粒子数的高维序列，旧近并列引理给χ→1。于是总体o(1)近优输出趋向真实产品边际，其观察KL趋向教师总相关。正floor下另有残余相关能力及风险下界。若无关尺度也可学习变小、存在自由cross协方差或涉及Adam轨迹，本结论不能自动沿用。
