# 可行性结论：当前曲率确认没有显示优于直接有限风险确认的明确用途

**本轮取得了一项有限但实质的统计可行性结果：小步不会自动节省验证数据；把曲率确认转成较大固定步的风险确认时，当前全标签转移界又损失了支持。作者因此在本阶段收束，不启动新独立验证。** 结论只针对原12个开发对象、三个已冻结幅度和所声明的界/规划口径，不否定所有独立验证方法。

这里没有验证样本。teacher真值用于oracle可行性，不能把表中规划端点称为实际置信区间、实际成功率或必要样本量。所有原A/B、锚点和方向保持；v1.6.2未修改。

## 固定比较与统计口径

本轮为每个旧锚点构造Q0及同方向t=.02/.10/.25的保持行长候选，全部36个非零候选保留。曲率支持评分Xc=−d^T Hphi^y d；直接有限风险评分z=log Qt−log Q0。后者均值就是这个固定候选相对Q0的风险改善，与旧600步HIGH/LOW是不同终点。

主规划用48个评分×6个固定样本量，总alpha=.05，单侧delta=.05/288。总体方差代入经验Bernstein表达式仅为规划proxy；同一评分的多个固定门共用事件。原raw概率不改，统计方差显式使用Pbar=P/sum(P)，保存质量与修正。范围来自全部256标签，未以观测样本范围代替。

## 1. 同量纲的小步验证几乎是同一统计问题

反射偶性和有限字母表光滑性给出2z_t/t²→Xc；非退化时均值和标准差同时缩放，因此信噪比不会因减小t自动变好。相应Hoeffding/经验Bernstein半径也具有同样正尺度等变性；这不是新的通用统计方法。

在三个真实负曲率对象上，t=.02时，直接z与曲率的matched-margin EB规划n比值只有1.00113至1.00223，相差约0.11%–0.22%。但此时实际有限收益只有1.65e−7至4.40e−7，远低于本轮固定的小风险尺度1e−5。更准的局部近似没有免费带来更可用的风险收益。

全部36个固定候选中9个有正收益，只有4个超过1e−5，没有一个超过1e−4；最大收益为6.20650e−5。其余27个负收益候选也完整保留。

剩余9个对象在目标方向上本来没有负总体曲率，因而不存在该oracle负曲率目标的支持。对有支持的三个对象，在本轮n=16,384以及65,536的均值中心EB规划端点，余量1e−4仍未过门。这个事实不能解读为这些样本量绝不会随机确认；实际样本均值/方差会变，界也可能保守。

直接确认1e−5收益时，t=.1仅一项真实均值略超过目标，其规划n约8,728,712；t=.02没有真实均值达到该门。t=.25把收益做大，但规划仍在约10.3万至86.2万。当前没有看到在原1024/4096训练量附近实现此用途的依据，也没有启动大规模抽样来追阳性。

## 3. 多候选复用的全标签转移界在t=.25失去支持

设e_minus=max_y[Xc−2z_t/t²]。已枚举表的逐点关系给E z_t≥.5t²(E Xc−e_minus)，可以由同一个曲率事件支持三个固定候选，不再花新的confidence事件。但该界可能非常保守。

|t=.25对象|直接增益|已知精确数值均值时的曲率转移下界|
|---|---:|---:|
|D3_N1024_r0|+2.64051e−5|−4.35048e−5|
|D3_N1024_r1|+6.20650e−5|−2.62309e−5|
|D3_N4096_r1|+2.22401e−5|−2.90338e−5|

三个候选确实有正数值收益，但这条转移下界即使在曲率均值已无统计误差时仍为负，因而增加验证数据不能让这条特定下界确认正收益。它不是候选无收益的证明，更不是所有曲率到有限风险转移都不可能的证明。直接z验证无需这一步转换。

在较小t上转移更接近，但收益也更小；在t=.25上单纯曲率门有较少的规划n，所确认的却不是同一个有限收益主张。不能把两种不同目标的样本量差叫作方法优势。

## 4. 原预算策略仍不是本轮的救援对象

用已知总体符号过滤原FULL，只留下2个HIGH选择，仍只捕获6项旧实质收益中的1项；相对always-HIGH留下平均风险差.00154132。对REF-only过滤留下3个选择、捕获2/6，风险差.00122941。这只是旧表代数，不是可部署方案或所有策略的最优上界。

原12点hP−hemp均为正，均值.00335213，与同数据拟合/选方向偏乐观相容；没有把它命名为已识别的选择偏差大小。锚点拟合、方向选择与抽样误差仍未分解。

## 5. 核验、成本与收束决定

全部12个曲率评分、36个有限评分的预定数值资格通过；192次GH PMF准备约5.41秒，另48次独立GL核对全部通过。曲率标签表来自旧保存对象，本轮没有重新计其获取成本；因此不把“查旧表比新算PMF快”包装成端到端算法优势。验证标签到来后，两者都可查固定表。

独立执行核验包含全标签重排/矩、4,248个规划行与8,640项临界整数n核对，总183,113项检查通过。核验范围不是严格Gaussian或浮点误差外包；cross-rule差异没有变成epsilon_num。两项只读复核都使用保存PMF，0新增积分。新25个NPZ共4,691,796字节本地保留并忽略，公开全部表、源和哈希。

本阶段没有识别出曲率确认相对直接配对风险验证的独特数据用途或有限收益支持，规划数据量又远高于原训练规模。因此我不启动下一阶段的新独立验证，不恢复正式72，也不继续添加规则成分。它提供了一个更准确的边界：局部几何可以解释准则，未必是最合适的有限风险验收工具。

如果以后有明确应用场景，先给出可提供的验证数据预算及必须确认的风险尺度，再考虑直接配对风险验证作为已有工具的应用；仍需新的独立合同。没有该用途时，当前子线收束，论文主线不必等待一个成功预算诊断。本轮不改稿，入稿建议另行列出再审查。
