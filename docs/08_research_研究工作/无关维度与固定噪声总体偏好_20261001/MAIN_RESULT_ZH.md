# 独立无关维度可以诱导有限粒子似然的伪相关

**论文可用的核心陈述。** 在正确指定、固定正方差的Gaussian–logistic模型中，增加与待估参数无关、观察上独立且分布已知的坐标，可以使原始prior粒子总体目标偏好错误的边界相关。即使教师观察完全独立，即使粒子数随总维数同步或按任意固定多项式增长，这种伪相关仍出现在实际总体极小点中；其固定active事件和完整积分观察KL损失不随无关维度稀释。

模型只学习固定active块的基础相关，新增n位在教师和每个候选中都是相同的独立公平位因子。所有均值为0、logit边际尺度a>0固定，active基础协方差位于固定正谱紧类。精确观察风险在添加这些坐标前后完全不变，但prior粒子的各维条件likelihood仍随机，进入共同log-mean后改变参数选择。该结论不适用于每个粒子的附加因子本来就恒定的情况。

令两位active教师相关为0≤theta<R，候选rho∈[-R,R]，0<R<1。记r_a(rho)为候选观察自旋pair矩，v_a=Var(log sigma(aZ))，J_K=E max_{k≤K}Z_k。对任意固定b、C>0，n趋无穷时在2≤K≤Cn^b及整个rho区间上一致有

\[
\frac{\sqrt{nv_a}}{J_K}\,\partial_\rho F_{n,K}(\rho)
\longrightarrow-\frac{a^2}{4}\{r_a(\theta)+r_a(\rho)\}.
\]

加号是关键：其势函数严格凹。值与导数的一致极限共同证明，对充分大n，theta>0时实际唯一全局极小点恰为R；theta=0时全部极小点恰为±R。固定K还可证明一般固定active协方差类上的C²极限，解释为对条件active log-likelihood方差的偏好。证明利用Gumbel精确pair积分和相对局部密度/上尾界，保留最高粒子近乎并列时决定参数方向的细项。

在a=1、R=.75的独立教师中，最终端点的完整观察KL至少1/128，同标签事件概率误差至少1/16。该解析结论不提供可计算的n阈值；有限n实验不能直接套用这个常数。对近优点，充分条件是总体误差epsilon=o(J_K/sqrt(n))，K=n+2时为o(sqrt(log(n)/n))。真值本身也已有o(1) raw regret，所以不能宣称任意o(1)近优点均错误。

另一个固定维、弱发射推论给出最小机制：独立教师、K2时，F(rho)−F(0)的六阶项为(10−3D)a^6 rho²/512。充分小a下，D2/3的实际最优点为0，D≥4转为±R；仅两个无关坐标就能翻转相关选择。这个a极限与固定a的高维极限分开证明，余项没有对增长D的一致性。

固定a=1的K4实验中，65,536独立bank给同一错误候选的评分差从n0的+.003350变为n14的−.000772、n4094的−.000379；18项共同95%经验Bernstein区间及6预定符号门支持反转。K2确定性剖面的3593项数值资格和10预定读数通过。实验没有新标签、模型训练或连续最优点认证；没有增长K的新增数值实验。

风险对象必须明确：raw优化随机K粒子预测器的期望log风险，这里评价积分模型Q。同Q精确边际化无关位使目标返回F_active,K+n log2，消除padding效应，仍可能保留active有限K偏差。均匀全维query、按维平均KL及总count风险会稀释；所学参数限已知active块，不覆盖全维自由协方差或实际SGD。

这个结果将论文的重点从“重要性权重会塌缩”推进到“参数无关的数据扩展破坏目标的参数选择不变性，并产生可证明的观察风险”。权重塌缩、Price、Gumbel及边际化本身均已有先例；本包不认证历史首创或ICML录用竞争力。证据和适用范围见REPORT (historical reference not distributed)、SCOPE (historical reference not distributed)及文献近邻 (historical reference not distributed)。本页不是新完整稿，v3.1保持封存。
