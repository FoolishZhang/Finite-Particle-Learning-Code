# 无关观测扩展可以破坏有限粒子似然的学习一致性

在一个正确指定、具有固定正logit方差下限的Gaussian–logistic模型中，增加分布已知、与待估参数无关的独立观测，可以使原始prior粒子似然的实际经验网格最优点学得伪相关。这个现象不只发生于固定少量粒子：内层粒子数与维数同比增长、外层银行数按多项式增长，也不能消除它。

具体地，教师为独立公平位，候选只学习已知两位active块的相关rho，其余n位在每个候选中都是相同独立因子。固定发射尺度a>0、相关网格含0和±R、0<R<1。取K=n+2、B=ceil(n^(1+eta))、eta>0，全部标签和候选共享这些完整prior银行。条件于任意预先给定的完整数据集，raw网格ERM选择±R的概率趋1；这是逐数据集统一的条件概率界，不是同一银行同时对所有数据集成功。

因此，raw学得模型的完整积分观察KL趋向固定正值。若标签向量iid来自上述独立教师，且与银行独立，则保持相同数据、候选、银行和N/B/K，把无关潜变量在log内精确边际化后，网格ERM恢复真值0，期望风险趋零；标签数只需是预先指定的任意发散序列N_n，可任意慢增长。固定active位置、有限网格、教师iid标签、数据与银行独立、精确算术，以及增长K的条件都不可省略。

有限预算也有直接学习证据。a1、n254、N1024、B8192下，16个独立训练流中，raw在K2/K4分别14/16、15/16次选相关端点。解析风险界、整数CP及完整标签计数枚举给出两项联合95%置信下的程序期望风险分离：raw相对表格likelihood基线的额外joint KL下界分别为.003656和.004290（向外取整）。这不依赖Gaussian参考求积的严格误差证书。另一个独立定义的K4配对检验有13/16次满足真风险改善>.001的充分条件，p=.01064；它检验事件概率，不是平均改善大小。

估计精度与目标偏差必须分开。固定K2和非零梯度主项点，总体梯度为Theta(n^-1/2)；Price方差为Theta(n^-1/2)，未加控制变量的标准Cholesky路径方差趋正常数，相对一致性分别需要B/sqrt(n)→∞与B/n→∞。noise-CV也有前一种预算的充分保证。它们估计同一个总体梯度，降低噪声不会改正目标偏好，也不直接给SGD保证。

固定K下的边际化不是完全修复：当前K2的RB几乎未改善。事后全状态诊断表明，有限标签条件下，即使先对银行取期望，其active目标的数值代理也可能选择高风险参数。该诊断基于冻结数值表，不是严格B∞证书，不改原统计家族。

这里评价积分观察模型Q；raw本身优化随机K预测器的期望log风险。完整joint KL与固定active事件保留损失，按维平均和全维均匀query可能稀释。没有自由全维协方差、未知active结构、连续优化或自然任务结论；没有新通用梯度方法或首创认证。论证与证据见REPORT (historical reference not distributed)及SCOPE (historical reference not distributed)。v3.1完整稿保持封存，本页为新核心陈述。
