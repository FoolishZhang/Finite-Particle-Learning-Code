# 两组尺度共同释放：无关目标消除、有限粒子边界与局部恢复窗口

日期：2026-10-04。本页为解析工作；0 新 RNG、0 模型积分、0 参数优化。有效尺度上一包、v8 及全部旧科学保持原字节。以下命题只涉及理想实算术总体准则，不能替代实际学习轨迹或原生浮点资格。

本页回答：当有效均值、有效尺度和无关尺度同时可变时，上一包的依赖塌缩是否仍是共同目标的必然结局？答案须分层。固定正无关尺度下的高维塌缩定理，不再覆盖共同自由的参数类；无关尺度的总体全局最优是允许的最小值。然而，这只消除无关块引入的额外偏差，仍留下有效块的有限 K 目标和实际优化问题。

**来源归属。** 原评分接口理论第5节 (historical reference not distributed)已证明零均值独立无关尺度的严格正总体偏导、正确分解身份和平方尺度偏差上界。[有效尺度理论](../有效尺度自由度与有限曲率_20261004/THEORY.md)已证明带无关碰撞量的尺度 Hessian 和谱下限相关类的可达门槛；其均匀粒子局部式又承接[09-29固定边际接口](../边际依赖接口_20260929/THEORY.md)及自由因子局部极小推论 (historical reference not distributed)。本页把这些已有结果放入共同参数类，补全有限 n 的碰撞端点及由连续性得到的窗口。Jensen、全局 regret 比较和增长 K 的一致性推论均不作为新的一般原理。

## 1. 共同参数类和完整目标

固定有效维数 m、有限整数 n≥1 与 K≥2。有效教师 Y∼P 位于 {0,1}^m，边际 p_i∈(0,1)。无关教师观察彼此独立、公平且独立于 Y。候选有效 logits 为

\[
X_i=\mu_i+s_iZ_i,\qquad Z\sim N(0,C),\qquad
C\in\mathcal E_\delta=\{[author-local path omitted]<\delta<1,
\tag{J.1}
\]

其中 s_i≥0。无关 logits 为共同尺度 τ≥0 乘 n 个独立标准 Gaussian。所有 K 粒子独立，且有效与无关 Gaussian 块独立于教师观察。令 θ=(μ,s,C)，有效正核为

\[
f_\theta(y,Z)=\prod_i\sigma\{(2y_i-1)(\mu_i+s_iZ_i)\}>0.
\tag{J.2}
\]

吸收公平无关标签的符号后，完整原目标和有效粒子目标分别是

\[
F_{n,K}(\theta,\tau)
=E\left[-\log\left\{K^{-1}\sum_{k=1}^Kf_\theta(Y,Z_k)
\prod_{j=1}^n\sigma(\tau G_{kj})\right\}\right],
\tag{J.3}
\]

\[
F_{A,K}(\theta)=E\left[-\log\{K^{-1}\sum_kf_\theta(Y,Z_k)\}\right].
\tag{J.4}
\]

所有期望包括相应教师和 prior；没有把一次有限 bank 的梯度当总体梯度。精确观察分布为 Q_θ(y)2^(−n)，故完整观察风险始终为 R(θ)=KL(P∥Q_θ)，与 τ 无关。有效尺度变化会改变 Q_θ；只有无关尺度路径保持精确观察模型不变。

允许紧有效类时，取 μ 的有界闭盒、s∈[0,S]^m、C∈E_δ；盒需包含文中使用的参数。零尺度在模型闭包中可行；若实现只容许正尺度，零点结论是闭包结论。独立块位置、无关均值零和无关观察公平仍是已知结构，不包含自由 cross-covariance、任务头或正则项。

## 2. 无关尺度的总体全局消除

**命题1（旧严格单调性的共同参数推论）。** 固定任意 θ，对每个 τ>0，

\[
\partial_\tau F_{n,K}(\theta,\tau)>0,\qquad
F_{n,K}(\theta,0)=F_{A,K}(\theta)+n\log2.
\tag{J.5}
\]

并有一致的偏差界

\[
0\le B_{n,K}(\theta,\tau)
:=F_{n,K}(\theta,\tau)-F_{A,K}(\theta)-n\log2
\le n\tau^2/8.
\tag{J.6}
\]

**证明。** 旧理论先条件于任意有效样本、实际标签及其它无关因子，对每个无关尺度 τ_j>0 给严格正的期望偏导。沿共同尺度 τ_j=τ 求和仍严格为正。微分由 n max_k|G_kj| 的有限 Gaussian 矩控制。τ=0 时各无关 likelihood 恰为1/2，逐实现给身份。偏差界即旧条件 Jensen 界相加；常数不依赖 θ。证毕。

因此，零 τ 可行时，

\[
\inf_{\theta,\tau\ge0}F_{n,K}(\theta,\tau)
=\inf_\theta F_{A,K}(\theta)+n\log2.
\tag{J.7}
\]

如全局最小点存在，其 τ 必为0，θ 必为有效有限 K 目标的最小点。紧有效类保证后者存在。不需先求出 θ，不需假定碰撞 χ(τ) 单调。更直接地，任意 τ>0 的参数都存在降低 τ 的总体下降方向；即使该处有效产品状态在有效坐标上稳定，它也不是共同目标的驻点。

记共同总体 regret 为 r(θ,τ)，有效目标 regret 为 r_A(θ)，则还有精确的非负分解

\[
r(\theta,\tau)=r_A(\theta)+B_{n,K}(\theta,\tau),\qquad r_A\ge0,\ B_{n,K}\ge0.
\tag{J.8}
\]

这不是随机梯度噪声分解，也不是观察风险分解。固定 n,K、紧有效类和有界 τ 时，若 r→0，则 τ→0：否则 τ≥a>0 的紧子集上，连续且严格正的 B 有正下界，与(J.8)矛盾。该论证不给数值收缩率，不直接推广到 n、K 同时变化的统一 τ 速度。

若 τ 的允许下端为 ε>0，所有总体最小点改为 τ=ε；此时剩余无关偏差至多 nε²/8，不能把它写成逐实现精确分解。softplus(raw)+ε 的有限实数 raw 达不到 ε，通常只有下确界；实算术中的边界值和 float32 舍入到 floor 需区分。总体严格下降也不说明 Adam、SGD 或有限样本训练能及时实现该下降。

## 3. 全局消除不等于固定 K 的观察恢复

在正确指定情形 P=Q_{θ*} 且 θ* 可行时，定义有效真参数的粒子偏差

\[
e_K(\theta_*)=F_{A,K}(\theta_*)-H(P)\ge0.
\tag{J.9}
\]

**命题2（标准 Jensen 的风险推论）。** 对任意共同参数输出，若其总体 regret 不超过 r，则

\[
R(\theta)\le r+e_K(\theta_*).
\tag{J.10}
\]

**证明。** 对完整 prior 积分使用 Jensen，F_{n,K}(θ,τ)≥H(P)+R(θ)+nlog2。另一方面，共同最优值不超过真有效参数配 τ=0 的 F_{A,K}(θ*)+nlog2。两式与 regret 定义相减即得。证毕。

固定 K 时 e_K 一般非零，所以(J.10)不认证完整风险恢复。允许零无关尺度也不让有限粒子评分变为精确似然。特别地，K=1 时可直接延拓上述设置：共同最优 τ=0，但有效目标正是上一包的 L(μ,s)，其最优仍为产品边际；任意依赖教师具有正总相关风险。

对固定可实现 θ* 的 Gaussian-logistic 模型，有限有效标签集、正核和 Gaussian 对数矩满足旧[正权均值对数误差引理](../无关权重结构与方差匹配_20261002/CONCENTRATED_THEORY.md)条件，因此 e_K(θ*)→0。当 K→∞ 且共同总体 regret r→0，(J.10)给风险趋0，无须另限制无关维数 n，因为候选 τ=0 精确消除整个无关块。它是理想总体近优输出的充分结论，不是当前程序达到该精度的证据。

若固定正 floor ε，可用 θ*、τ=ε 作比较，得到

\[
R(\theta)\le r+e_K(\theta_*)+n\varepsilon^2/8.
\tag{J.11}
\]

K→∞、r→0、nε²→0 是由本界给出的充分条件；本页不称其必要。该增长 K 比较与上一包固定单位无关尺度、n增长的塌缩定理处于不同参数约束中，没有矛盾。

## 4. 零无关尺度处的共同 Hessian

记

\[
\mu^0=\operatorname{logit}p,\quad
D=\operatorname{diag}\{p_i(1-p_i)\},\quad
\Gamma=\operatorname{Cov}_P(Y),\quad R_Y=D^{-1/2}\Gamma D^{-1/2}.
\tag{J.12}
\]

在有效产品边际 s=0、μ=μ⁰、无关 τ=0 处，原目标与精确观察风险的所有 μ、s、τ 一阶导均为0。固定 C 求导时，共同原目标 Hessian 为

\[
\nabla^2_{(\mu,s,\tau)}F_{n,K}
=\begin{pmatrix}
D&0&0\\
0&D-(1-1/K)(\Gamma\circ C)&0\\
0&0&n/(4K)
\end{pmatrix}.
\tag{J.13}
\]

这里 C 不识别，C 块及其与这些参数的交叉块全为0。精确风险的尺度块为 D−Γ∘C，μ块为D，无关块和所有无关交叉块为0。

**核验。** 有效块直接取上一包 χ=1/K。若先给 n 个无关坐标各自尺度 τ_j，则每个零尺度的一阶 log-kernel 标记为 G_kj/2，二阶为−G_kj²/4。负 log-sum-exp 的期望 Hessian 对角为1/4−(1−1/K)/4=1/(4K)，不同无关坐标因 Gaussian 独立均值零而交叉为0。沿共同 τ 方向相加即 n/(4K)。有效—无关交叉同样因独立 Gaussian 的一阶矩为0而消失。μ—尺度块与旧自由均值证明相同。有限 n,K 的 Gaussian 多项式矩允许微分交换期望。

令

\[
\lambda=\lambda_{\max}(R_Y),\qquad B=\delta+(1-\delta)\lambda.
\tag{J.14}
\]

旧 Schur 乘积极值为 sup_C λ_max(R_Y∘C)=B。取顶端单位特征向量 v，令 q_i=sign(v_i)、C†=δI+(1−δ)qqᵀ、N=∥D^(−1/2)|v|∥₂、a=D^(−1/2)|v|/N≥0。沿物理可行激活 s=ta，

\[
\partial_t^2F_{n,K}(\mu^0,ta,C^\dagger,0)|_{t=0}
=\frac{1-(1-1/K)B}{N^2},\qquad
\partial_t^2R|_{t=0}=\frac{1-B}{N^2}.
\tag{J.15}
\]

因此存在三种严格区分的情况。

1. 若 B<K/(K−1)，产品边际在整个 C 类上对 μ、s、τ 具有一致正横向曲率，C 方向平坦。共同产品流形局部稳定；这不说明它全局最优。若 λ>1，仍存在改善观察风险而提高原目标的激活方向。
2. 若 B>K/(K−1)，C† 处存在合法非负尺度方向，同时降低原目标和风险。共同产品参数 (μ⁰,0,C†,0) 有正的均值/无关方向和负的有效尺度方向，故是带平坦 C 块的鞍点。
3. 等号时二阶式不判定，需更高阶；λ=1 即两两不相关，不能据此断言联合独立。纯高阶依赖不由上述二阶风险方向识别。

**不可省略的参数化边界。** 第二种情况不意味着每个 C 表示的产品参数点都是欧氏鞍点。在 C=I 时，有效 Hessian 为 D/K>0，邻近 C 仍可能保持正曲率。因 s=0 时所有 C 表示同一产品观察分布，可以沿 E_δ 内连续路径由任何 C 等目标地转向 C†，然后激活；这是一条先平坦后下降的可行路径，不能冒称任意起点都有即时负曲率。固定 C 的无约束负特征向量也可能不在 s≥0 锥内；这里只对所构造的 C†、a 保证可行。

这里的局部稳定性使用显式坐标 (μ,s,C,τ) 的欧氏邻域。在 C=I、固定有限 K 时，正横向曲率及连续性实际给出这种参数坐标下的局部最小流形；但它不等于自由 Gaussian 因子坐标或观察分布空间中的局部最小。若用有效协方差因子 A 表示 Σ=AAᵀ，则零尺度对应唯一 A=0，而可行路径 A=t diag(a)L_C† 在任意小的因子邻域内实现(J.15)的负方向。当(J.20)成立时，该因子路径排除了零因子处的同类局部最小。观察分布 Q_(μ⁰,ta,C†) 也连续趋向产品分布并沿负方向降分。由于零尺度把所有 C 识别为同一模型，坐标映射在这里退化；不能据此声称存在与参数化无关的普遍“训练陷阱”。严格正初始化和实际使用的 Cholesky/scale 参数化需要单独说明。

## 5. 有限 n 的碰撞连续性与两个端点

以下 χ 只由无关权重定义，与离开产品基点后的完整粒子权重不同：

\[
W_k(\tau)=\prod_{j=1}^n\sigma(\tau G_{kj}),\quad
\pi_k(\tau)=\frac{W_k(\tau)}{\sum_lW_l(\tau)},\quad
\chi_{n,K}(\tau)=E\sum_k\pi_k(\tau)^2.
\tag{J.16}
\]

**命题3（连续性和有限维硬尺度端点）。** 固定 n≥1、K≥2 时，χ 在有限 τ≥0 上连续，χ(0)=1/K；对 τ>0 有1/K<χ(τ)<1。并且

\[
\lim_{\tau\to\infty}\chi_{n,K}(\tau)
=\chi_\infty(n,K)
=P(M=0)+\sum_{r=1}^K\frac1rP(M=r),\qquad
M\sim\operatorname{Binomial}(K,2^{-n}).
\tag{J.17}
\]

特别地，

\[
\chi_\infty(n,K)\ge1-\binom K2\,4^{-n}.
\tag{J.18}
\]

**证明。** 每个有限 Gaussian 输入下，π 随有限 τ 连续、严格正，碰撞在[1/K,1]内，因此支配收敛给连续性；τ=0 所有权重相等。τ>0 时独立 W 非退化且连续，几乎必然不全部相等，所以严格大于1/K；有限 τ 全部 π 正且 K≥2，故严格小于1。

令 M 是 K 行中全部 n 个 G 都为正的行数。每行此事概率2^(−n)，独立，故 M 为上述二项式。若 M≥1，这些行的 W→1，其余 W→0，极限碰撞为1/M。若 M=0，则每行 L_k=Σ_j min(G_kj,0)<0，且 W_k(τ)/exp(τL_k)→1。条件于没有全正行，各 L_k 独立并具有连续分布，最大值几乎必然唯一，所以该行权重趋1、碰撞趋1。再次用有界支配收敛得到(J.17)。最后1−χ∞≤P(M≥2)≤E binom(M,2)=binom(K,2)4^(−n)。证毕。

这个端点一般不等于1。有限 n 下多个全正粒子有正概率，此时它们共享极限权重；不能把固定 n、τ→∞ 和上一包固定 τ、n→∞ 的极限混为一谈。(J.18)可能很松或为负，只作充分端点条件，不作为 χ 全曲线近似。

## 6. 不要求碰撞单调的局部恢复窗口

在产品基点固定任意 τ，旧带权式仍给

\[
H_s^F(C;\tau)=D-1-\chi_{n,K}(\tau) (historical reference not distributed).
\tag{J.19}
\]

此处 μ、s 梯度为0，但若 τ>0，共同目标在 τ 方向仍有严格正梯度。因此这里只判断有效激活方向，不称完整共同局部极小点。

**推论4（窗口与至少一次过门）。** 若

\[
(1-1/K)B>1,
\tag{J.20}
\]

则存在 η>0，使所有0≤τ<η 下，C†、a 的充分小有效激活同时降低原目标和观察风险。证明只用χ(0)=1/K、连续性和严格间隔。更进一步，若

\[
\chi_\infty(n,K)>1-1/B,
\tag{J.21}
\]

则还存在有限 T，使所有 τ>T 下的有效产品状态一致于 C 类具有正尺度曲率，而同一 C†、a 激活仍改善观察风险、提高原目标。在(0,∞)至少存在一个 τ_c 满足 χ(τ_c)=1−1/B。条件 binom(K,2)4^(−n)<1/B 足以保证(J.21)。

本推论不宣称τ_c唯一，不宣称 χ(τ) 全程单调，不把 χ 的下降和完整目标的下降混成同一个定理。原目标随每个正无关尺度严格增加已由另一证明成立；归一化碰撞是不同函数。数值若只取几个 τ，也不能据此升级为全程单调证明。

当(J.20)不成立时，小 τ 窗口不由本论证保证；增加 K 可改变门槛，但不自动改善任意当前模型。即使窗口存在，给定有限幅度激活、有限训练结果和给定原生 API 都须分别验证，不能用二阶符号认证任意步长。

## 7. 可检验含义和论文边界

- 固定正无关尺度下的 active 塌缩不是共同自由参数类的必然总体最优结局；τ>0 时总有保持观察模型的无关下降方向。
- 足够小 τ 能否释放依赖激活，还受教师观察相关强度、允许的 C 类和 K 约束。共同学习中的两类尺度不能只看各自都缩小了多少；主结论依赖预定输出的观察风险，训练 bank 的碰撞与窗口位置只作描述性诊断。
- χ 门槛是产品边际处的精确局部机制，不是一般状态的梯度符号判据。实际轨迹远离产品基点、每次有限 bank 的噪声、softplus 梯度尺度和相关参数化都可能影响实现。
- 本页新有限 n 端点和窗口不要求增加观察数据；数值碰撞、独立总体评分、真实更新和风险积分仍须各自事先冻结合同。由已实现轨迹后选阈值、选择最优 checkpoint 或追加预算过门均不由本页授权。
- 如后续实验同时释放有效与无关尺度，可报告该受控程序在预定输出上是否改善风险，并另列描述性窗口诊断。本轮训练 bank 的 χ 不作为统计确认进入总体曲率窗口的证据；此种确认需要另有事先冻结、独立且合格的总体评价。一次成功不证明普遍自动恢复，一次失败也不否定(J.5)的总体下降方向。
- 共同目标的全局消除、固定 K 的局部稳定性、增长 K 的总体恢复、有限预算优化是四层不同结论。论文应依赖已完成的证据层级，不将后两层由前两层自动补齐。
