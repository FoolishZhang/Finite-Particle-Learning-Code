# 冻结前数值资格决定：保持原接口研究对象，保留失败

本页在任何新科学数据/prior/训练之前编写。固定制造数组的compute检查有6项：5项通过，NEAR_FREE的共同τ梯度未过原4e−5绝对误差门。

原API32梯度为16.034530639648438，math64为16.034485150598943，差4.548904949430721e−5；最大梯度相对差约2.837e−6。分数差6.7445e−6，通过原1e−4门；该例其余14个梯度坐标的最大差约1.44e−6。完整向量见`artifacts/joint_scale_learning/COMPUTE_QA.json`。不改容差、不换fixture，也不把该例重新标为通过。

结构资格、独立有限差分、原API调用、Adam和修复检查支持当前代码实现了指定程序。作者决定继续原定native32程序的固定预算研究：本轮直接研究这个公开评分接口下的实际受控学习输出，其观察风险由独立积分评价。将模型输出与真实产品边际的风险比较，不需要把训练梯度冒称为实算术梯度。

因此要分开两项结论：

- 可报告指定原API32程序在新数据上的输出风险及预定统计门；这些是该有限精度程序的经验结论。
- 不宣称该程序已通过全部math64梯度近似资格，不把数值差的相对大小当作整条轨迹误差界或证明它无影响。主384状态的同一资格门仍全部保留，独审另核相同状态；任何新增失败会如实进入最终数值总表。

本决定不修补理论，也不升级旧失败。理论仍为实算术总体准则；连接到实际程序的强度受此数值边界限制。若后续发生非有限loss/梯度、非法参数或真正实现错误，记录失败并停止受影响执行，不换seed自动重试。参考积分资格另按原门判定，不能由本决定豁免。

确定性检查记录与科学抽样分别记账。实现代理曾执行kernel check两次（一次只在返回字典阶段TypeError，数值断言已完成），compute结构/数值check一次，另一次定位诊断；root又分别保存kernel check和compute check各一次。所有这些都没有科学RNG、模型PMF积分或独立训练输出；旧失败源码未原样保存的事实见KERNEL_DEVELOPMENT.json。
