# 中文核心：允许共同缩放，不等于有限学习已经恢复依赖收益

上一包说明固定nuisance表示时，释放active均值/尺度仍可导致产品边际风险。本轮进一步允许共同nuisance尺度学习，得到明确边界：总体目标的全局最优会把nuisance尺度推到允许的最低值；零尺度可行时，额外无关项精确消去，但active有限K偏差和实际优化问题仍在。

16份新数据、K100、512步的受控原API学习中，NEAR/UNIT两个初始化的FREE输出平均nuisance尺度已降至.045799/.045229，却均未确认优于真实产品边际风险.0027110543。NEAR的FREE−产品区间为[+.000250534,+.000974831]，反而为正；UNIT跨零。直接去除无关块的ZERO有限K参照则在两初值都确认更低风险，区间分别[−.001165817,−.000156492]、[−.001577875,−.000716186]。

六项原风险门效应3/6、精度6/6。FREE−ZERO由原共享区间派生的范围在两初值均正，未新增检验。它说明当前模型与预算具备学习有益依赖的能力，但共同优化没有自动实现同样的净风险收益。此结论限定当前程序，不能推广为增加预算也无法恢复、固定nuisance定理已适用于所有自由参数，或某一噪声源已被因果识别。

FREE输出相对自身产品边际仍有描述性logscore收益；未过真实产品基线不等于没有依赖。C=I附近的产品局部稳定也只是在显式(s,C)坐标中成立，零尺度的非识别使其不能泛化为参数化无关的陷阱。
