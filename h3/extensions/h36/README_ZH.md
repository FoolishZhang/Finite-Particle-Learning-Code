# 有限粒子学习中的输入访问与联合输出

本紧凑扩展对应h3.6关于输入访问与输出因子化如何选择性改变固定粒子数下相关学习的研究。材料包括一般结构证明、英文技术附录A–H及参考文献、新神经端点保存矩阵与配对统计、同TRAIN参照摘要，以及独立对象上的有限样本风险实验。精确文件清单见manifest。

安装检查与绘图依赖，输出选择源码目录外的新路径：

```text
python -m pip install -r h3/extensions/h36/requirements.txt
python -B h3/extensions/h36/tools/check.py --output ../h36-saved-check.json
python -B h3/extensions/h36/tools/plot.py --output-dir ../h36-neural-redraw
```

检查器核对仓库声明文件的SHA，并完成以下保存算术；无需下载可选历史大数组。

- 新神经确认：d8/K4、四种结构、正负教师、固定单一起点，共96个相关矩阵，统计单位为12份独立配对数据集。由矩阵重建加权奇响应、四项配对均值/SD及Bonferroni–Student近似同时95%区间。
- 旧同更新复评：原12份数据补齐更新后的事后统计，独立于新确认报告，不合并重复数。
- 同TRAIN诊断：提供经验似然参照、解析后验KL、奇偶矩阵描述的保存摘要与文件身份；不重新拟合参照或计算后验。
- 旧R64风险：三组Gaussian–logistic模型、K8、固定局部/全输入指数倾斜族，每个(N,S)有64份独立数据，共256份。重聚合固定beta=1控制与原始配对风险差、领先理论、参数协方差及有限R偏差–方差恒等式。

新神经程序比较局部输入乘积输出L、全输入乘积输出A、全输入四个双变量块B和全输入完整联合输出JNT，全部28个候选相关自由学习。`neural_design.json`的噪声条目是**方差**。同一数据ID的正负教师共用底层随机数，各方法共用有符号数据与训练seed，不同ID独立。主输出始终为28000次更新后的最后合法端点，不选择最佳起点。这些是固定程序输出，不是已认证的神经类内极小。

资源修订在新数据生成之后、读取新主效应之前冻结；按预定ID/seed或完整状态恢复纯资源中止轨迹后，取得全部96个满步端点。旧资源受限结果、旧事后复评与新确认保持各自身份。B减A跨块等价针对预设±.05尺度内的加权响应，不是严格零差，也不是28条相关逐坐标等价。[附录H](notes/APPENDIX_NEURAL_EN.md)给出完整设计和诊断定义。

R64确认结果是本扩展新加入的内容，旧v1.3.0公共材料没有包含它。其风险为指定数值生成分布下的真实联合观察KL，离线评价；固定beta=1得分控制只改变风险差估计，不参与拟合。更充分恢复相关降低衰减偏差、增大方差，风险优劣因此随信号改变。该证据属于旧三组模型，与新神经结构确认不同。紧凑提取的数值随后被正式全量核验确认为数学成员完全相同，待核元数据不代表另一套分析。见[风险理论](notes/APPENDIX_RISK_EN.md)和[数值细节](notes/APPENDIX_EVIDENCE_EN.md)。
