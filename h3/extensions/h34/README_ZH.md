# h3.4 紧凑保存证据

本 v1.3.0 增量材料对应 h3.4 研究稿，含同质及异质的30个分支点与预先计算的解析响应、未知通道全部6个总体驻点、6份完整坐标局部风险记录、两组18状态矩表，以及证据附录使用的紧凑执行统计。作者为 ZHANG；不声称论文已接收或经过外部独立审查。

适配图区分提议可用的输入：F无自由倾斜，L使用本组观测，A使用其他组观测而仍保持分解形式。提议基底仍随通道改变。理论线来自预先计算的解析常数，未由图中数值点拟合。分支点为具有数值资格的确定性驻点，不是风险样本，也不认证连续分支或全局最优。

## 可执行核验

使用 Python 3.11，在单独环境安装本目录 `requirements.txt`。实际测试版本为 NumPy 2.3.5、Matplotlib 3.11.2。在仓库根目录执行，输出位置须为源码树外新路径：

```text
python -B h3/extensions/h34/tools/check.py --output ../h34_saved_checks.json
python -B h3/extensions/h34/tools/plot.py --output-dir ../h34_redraw
```

检查器核对本增量文件身份，利用一维保存矩独立因子化重建4/58/64维完整 Hessian、得分协方差、Schur补、影响协方差和风险，再核保存坐标、差值与曲线算术。风险数值函数原样抽取自冻结的内部保存算术审核，仅导入、常数和公开文件包装作了投影。这是内部算术核验，不是外部科研审查。绘图器由保存点与解析常数重画 PNG。两条命令均不运行模型求积、抽样、训练、拟合或优化，也不重放原始PMF积分。

## 范围与统计单位

- 六份风险记录为两种确定性矩规则下的 F/L/A，不是六次统计重复。局部期望风险定理的对象是根N局部teacher eta_N = h/sqrt(N)下、指定紧域上精确经验全局极小估计量，依赖固定维数及粒子数、精确粒子期望及所列正则性与局部化条件。同数据plug-in使用有效边际第一阶段通道估计；没有未知通道的有限N实验。joint与同数据plug-in具有相同领先协方差；在定理条件下通道增加公共 `1/(2N)` 领先项。
- 六个未知通道总体点采用固定teacher比较和完整主/高规则驻点资格。正的边际KL和与负的联合KL差是不同读数，均不能推成普遍风险改善。保存字段 `lambda` 对应稿件中的通道 alpha；逐点驻点比较不认证 t=.1/.2 全局性，也不声称与渐近首项完全相等。
- 旧9端点分解为预先选定的面板。两项比较固定theta的局部profile及joint参考，不是全局regret；高阶覆盖仅限记录的r0子集。A减L统计使用4次完整数值重复与样本SD；joint-A固定点噪声使用3次完整重复与样本SD。这些不是有限N验证数据集，也不是配对标准误。
- 旧风险、预算和学得提议材料仍在 [h3](../../README.md) 及 [h33](../h33/README.md)，保持原字节与统计身份。
