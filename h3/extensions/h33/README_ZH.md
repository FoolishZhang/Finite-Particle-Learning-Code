# 预算复评与学得局部提议材料

本目录是v1.2.0对现有h3出口的增量，支持h3.3及其文字修订稿的D.5/D.6。
原v1.1.0的h3科学文件及其清单逐字节保留。本包不是新实验、论文公开发布或匿名补充材料。

完整范围与命令见[英文说明](README.md)。从公共仓库根执行：

```text
python -I -B tools/verify_release.py
python -I -B h3/extensions/h33/tools/check.py --mode all --output ../h33-check-001.json
python -I -B h3/extensions/h33/tools/plot.py --output-dir ../h33-figures-001
```

输出须为源码树外全新路径。检查只核文件、保存重复的算术及隔离导入；绘图只读保存量。
不采样、不积分、不训练，也不运行新的科学随机数。

- D.5保留同24数据集、两起点的288条风险及96条新参照诊断；原12/48、新参照36/48、
  高预算48/48均保留。梯度诊断第二门是最大坐标标准误。family2是回顾性预算比较，
  不取代原family4，不筛选通过者，也不证明等效或全局最优。
- D.6保留三训练池两个嵌套规模的六对raw/sym冻结密度、全部checkpoint分数与54份逐R保存量。
  完整g/H/B矩阵给出独立预测和同银行预测；family36包括12个D、12个W_ind与12个W_same，
  R=16、df=15，区间条件于冻结密度。全部区间达到预定精度与全部同银行余项非零可以同时成立。
- 旧family24与1/12原样另列，raw对照和其配对协方差信息不删除、不作新增显著性结论。
- 单提议GH28/GH36只是预定一个提议的普通阶差资格，不是六提议连续积分误差证明。
- 不包括原始粒子、均匀数、训练物理数组或逐B完整导数数组。因此不宣称原逐B核验、
  完整生产重放、重新优化或学得估计量的有限样本风险验证。
