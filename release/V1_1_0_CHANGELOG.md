# v1.1.0: h3 code and compact evidence

Adds the current h3 scientific code, proof sources, all 96 observed validation datasets (153,600 rows), 576 fitted coordinates, 576 reference diagnostics, 864 risk-precision records, 65,536 saved J1 proposal differences with their paired differences, and the three figure sources/images.

New public tools verify file identity and saved arithmetic, import 26 original modules in 3 isolated namespaces, and render figures by calling the original functions. All three re-rendered PNGs matched the archived bytes on the tested environment; 92 pre-existing exact rational checks passed. These are separate operations, not a new scientific run or proof of full reproduction.

Original source modules and three proof files are byte-preserved; public CSV projections are lossless and hash-mapped. The joined proof reading page concatenates original sections and adds explicit HTML navigation anchors; the scientific text and display mathematics are unchanged. The original runners retain historical management locks and are source-readable, while public tools intentionally support saved-value verification and plotting. Full particle banks, PMF caches and optimization replay are not packaged or rerun.

The v1.0.0 and data-v1.0.0 tags/assets, h2.2 anonymous snapshot, licenses and third-party source remain unchanged. This named repository is not an anonymous review package. Root release metadata and citation now describe the additive v1.1.0 scope; no h3 manuscript PDF is newly published here.
